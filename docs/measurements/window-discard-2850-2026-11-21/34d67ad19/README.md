The prior version's single option also took 763 discarded assignments.

All 1,272 spelling/policy comparisons and 144 linked boundary programs matched the ordinary build. The [corpus results](corpuses.tar.xz) add a separate `--node-window-assignments` compilation to the ordinary and `--node-window` modes. All three compiled byte-identical objects and produced identical diagnostics on each of 1,371 files.
