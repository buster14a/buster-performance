# Explicit void-literal statements in the production reader

[Buster #3223](https://github.com/buster14a/buster/pull/3223) adds the statement `((void)0);` and equivalent groupings to `--node-window`. The source is [4d0bba342](https://github.com/buster14a/buster/commit/4d0bba342eb2d9eebf149bd3bd67b82023406a7b). This record covers correctness on the development host. The [locked 9700X record](../window-compile-2850-2026-11-21/4d0bba342) covers compile time, instructions, faults and object identity on frozen SQLite.

The source test asks for exactly four admitted statements and compares all checked-value fields and both native rows' source positions. Four other statements in the same function use a variable, a side effect, a comma or an unbraced control body. Shard 5/8 passed all 210,487 assertions. [Checker log](results/checker.log), [admission counters](results/fixture.err).

The [spelling and context generator](scripts/matrix.py) ran 159 source forms under four warning policies, in both syntax-only and object modes. It includes suffixes, side effects, expressions with diagnostics, typedefs and qualifiers, macro expansions, line remapping, for clauses, statement expressions and control-flow positions. All 1,272 comparisons matched status, stdout, stderr and emitted object bytes. The window admitted expressions in 384 comparisons (504 admissions). Run the script with the compiler path and an empty directory. The columns in the TSV are case index, policy index, mode, equality flag, ordinary exit status, object-produced flag and window admissions. [Raw comparisons](results/matrix.tsv).


The [boundary and runtime tests](scripts/boundaries.py) vary the statement's offset across 36 padding lengths, including both sides of powers of two through 1,024. Each source executes two checked control-flow outcomes under Tier 0 and Tier 1 with debug off and on. All 144 programs had identical whole objects and ran successfully. All 72 non-debug cases had actual admissions. On this source revision the 72 debug configurations use the ordinary reader. [Per-program admissions and hashes](results/boundaries.tsv).

All 1,371 ordinary and option-on object pairs on the frozen sources compiled without an output difference. The [archive](results/corpora.tar.xz) includes each of SQLite, the 34 Lua files and the 1,336 musl translation units, both exit statuses, both SHA-256 values and the full diagnostic comparison result. To replay, use [the same corpus arguments](scripts/corpus-arguments.sh). Run the corpus script from the extracted inputs with environment variables `cc`, `debug_log` and `src_root` set to the absolute compiler, result directory and inputs directory.

Against ordinary main in a separate seven-round locked comparison, the cumulative option saved a paired median 2.978 core cycles per token. Its paired wall-time change was −0.1175 ms with a range of −5.998 to +0.446 ms. The compiler's own option-off control and the duplicate baseline are included in the [controlled measurements](../window-compile-2850-2026-11-21/4d0bba342/cumulative/).
