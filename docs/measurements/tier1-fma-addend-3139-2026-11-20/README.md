# Memory addends in scalar FMA

[PR #3139](https://github.com/buster14a/buster/pull/3139) compares [269f35954a](https://github.com/buster14a/buster/commit/269f35954a8da56378f5b56899b2dcc458be53a6) with [de4e763e86](https://github.com/buster14a/buster/commit/de4e763e8675b232169815ba0afae8025773783b).

A scalar FMA can take its single-use addend directly from memory. The selector keeps the existing preference for a memory second multiplicand. For the addend it uses the 213 form when register assignment preserves the original NaN priority, including when the multiplicands coincide or a constant or integer conversion proves that one cannot be NaN. When the result aliases the first of two possibly distinct NaNs, it loads the addend into the reserved XMM scratch and uses the ordered register form. The existing adjacent-load and address-folding checks still apply.

The 44-leaf fixture emits 40 memory-addend instructions in the new compiler and zero in the parent. Across x86-64-v3 and znver5, with normal and post-allocation scheduling, the floating-point tests passed 1,703,936 result/exception comparisons and a separate 360,448 raw-MXCSR comparisons per configuration. An independent register-pressure test passed 115,200 comparisons and verified two faulting-load orderings per build. All 720,896 observations across 44 actual musl functions agreed with the parent, including the existing differences from Clang. Twelve of 1,336 musl objects changed, with 10 fewer text bytes in total.

In Opus 1.5.2 all 56 encoder and placement comparisons retired fewer instructions (0.010–1.017%). Of those, 28 took fewer cycles. Cycle medians ranged from 4.20% faster to 4.28% slower on the local Ryzen 9 7940HS. All 30 upstream test runs passed. Encoded packets and decoded PCM matched across the Buster builds. Rebuilding with the final selector reproduced all 578 candidate object hashes across two target architectures and the portable and CPU-dispatch configurations. In separate fused double-precision square-plus-bias loops the four placements retired 11.82% fewer instructions. Cycle changes for dependent loops were mixed.
