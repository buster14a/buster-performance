Assembly roundtrip
Compiling checker source to .s and reassembling requires -march=znver5 to retain original NOP encodings. The unique printed `fadd %st, %st(0)` within check_test_action_constraints reassembles as D8 C0 although the direct C build encodes DC C0. Original C normalize_x87_roundtrip.c replaces only that line, within the uniquely expected function, with `.byte 0xdc,0xc0`. This restores byte-for-byte equality of the ENTIRE reassembled zero object with its original object in both revisions; no semantic-equivalence assumption replaces this equality. Both complete zero linked images also equal the corresponding ordinary build/compiler byte for byte. The unrelated build.sh shifts/compiler-0 image is not used as this reference because its retained empty padding symbol changes metadata.
