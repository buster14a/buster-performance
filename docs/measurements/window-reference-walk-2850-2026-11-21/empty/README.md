# Which expression subtrees contribute a body reference?

The baseline is Buster `325883abf9607ac726966a0af2097377832d53ac`. Apply `reference.patch` to that revision. The variant operates inside the ordinary checked-program builder before lowering. For each block of 16 checked nodes it records a two-byte mask. A set bit allows the ordinary reference walk to finish that subtree immediately. The bit certifies that the walk would contribute no named reference, compound initializer or statement region. A pair of vector permutations propagates the proof from operands in the current and preceding block, to a maximum of six rounds. Unknown and distant operands keep the existing walk. The experiment leaves its graph and the reference list's original format in place.

On frozen SQLite 260,226 of 323,623 checked nodes carried this proof. On the self-compilation input it certified 827,648 of 1,407,416 nodes. These counts include nested subtrees. Each corpus TSV records the resulting object, references and diagnostic hashes plus the total and certified node counts. The paired witness covers 1,372 source files in ordinary, debug and warning-enabled compilation. All 4,116 pairs returned success and matched byte-for-byte on the ELF, stdout, diagnostics, per-body reference lists, required object bits, reached regions and compound initializer bits. Run `BUSTER_COMPILER=/path/to/compiler python3 compare.py CORPUS FLAGS... SOURCE.c ...` to reproduce the comparisons.

The separately linked fixture executes three functions with 300 inputs each and compares Buster's result with Clang's checksum, 2508071845. Certification covered 45 of 69 nodes. A diagnostic arm forces all leaves to be considered empty. The reference witness changes and the compiler fails to emit the fixture. Run `bash reach.sh "$PWD" /path/to/compiler /tmp/reach-2850` with Clang on PATH. Only the off, on and diagnostic arms differ in this first implementation.

Three paired six-process rounds used a single CPU on a Ryzen 9 7940HS, with the Develop build. Each round ran pristine, private disabled and enabled in symmetrical order, with identical objects across all 36 processes. The SQLite paired median was 7,082,161 fewer retired user instructions and 679,298 more user-plus-kernel cycles against pristine. Against private disabled it was 7,449,541 fewer instructions and 5,837,187 more cycles. Self-compilation used 1,588,386 fewer instructions and 12,948,708 fewer cycles against pristine. These are local screening measurements. The production target uses a locked Ryzen 7 9700X. The local SQLite cycle result leaves this a research branch. Run `python3 summary.py local` for the original paired reduction.
