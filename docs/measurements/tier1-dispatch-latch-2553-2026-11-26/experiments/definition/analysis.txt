------------------------

script arguments, environment and Valgrind options. Each binary was installed only after
all five preceding variant runs finished, and was compared byte-for-byte with its source.

Controlled Lua command recipe
-----------------------------
For baseline, then definition, install that variant's verified Lua binary at
/dev/shm/buster-2553-lua-stable/lua. Never replace it until all five runs have completed.
Set LC_ALL=C and VALGRIND_LIB to the extracted pinned valgrind-2553/usr/libexec/valgrind.
Change directory to inputs-2553/scripts. For NAME in arithmetic calls tables strings closures:
  /dev/shm/buster-2553-lua-stable/lua NAME.lua
  valgrind-2553/usr/bin/valgrind --tool=callgrind --dump-instr=yes
    --extra-debuginfo-path=valgrind-2553/usr/lib/debug --callgrind-out-file=VARIANT/NAME.cg
    /dev/shm/buster-2553-lua-stable/lua NAME.lua
The valgrind paths are absolute below /workspace/scratch/dfc32981403d in the actual run.
Compare both outputs with outputs-2553/oracle/NAME.out. Disassemble that variant's binary
with objdump -d --no-show-raw-insn and join the capture with gap count, object ???, bias
0x108000, its own lua.kinds and GAP_INSTRUCTIONS=1. Archive the raw capture with gzip.
The exact tool binaries and source scripts are fingerprinted in tools.sha256.
