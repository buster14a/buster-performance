# Reuse each machine record's containing inline instance

Compiler [#3131](https://github.com/buster14a/buster/pull/3131) at `90f5b66462611889ba62555221df59f5ac9e52f0`, compared with main `78851ffc6604386c0fb25472af53c107ec2a2be3`, on a Ryzen 9 7940HS. The old publisher scanned all inline instances to map an expanded source entry to its outermost call and then searched again to name the innermost instance. SQLite had 309,425 ancestor lookups, 36,369,324 scanned instance rows and 295,334 secondary lookups. Of 190,440 expanded records, 168,680 reused the preceding expanded record’s instance. The new publisher uses the ordered table, immutable parent links and the interval of the last successful search. [Query counts](queries.tsv)

Eight alternating local pairs after warm-up at `-O2 -g` reduced SQLite compiler instructions by 0.571% and paired cycles by 1.590%, with mixed individual cycle signs. Every SQLite `-O0 -g` pair used fewer cycles. Lua parser and VM used 0.526% and 0.199% fewer instructions. On top of the #3129 debug range stack the same source change reduced SQLite debug instructions by 0.699%. The release control moved by less than 0.001% in each comparison. Direct 9700X measurements are pending. [Main counters](cached.tsv) and [stack counters](stack.tsv)

A simpler alternative, replacing the linear scans with binary searches alone, saved 0.441% of SQLite debug instructions. The published variants and profile data preserve that comparison. All 1,336 musl and 70 application objects matched the parent's bytes. Both Lua executables and ten output checks matched. The standalone GDB/LLVM cross-check passed 4,027 checks and the #3129 integration passed 4,082. [Musl objects](objects.tsv) and [simple alternative counters](simple.tsv)

In a separate integration with the independently owned lexical-block change #3118 at `e00b28f6cf0d3a1ab93bb4b0329eb1f49fe1c155`, both compilers passed the GDB cross-check. The candidate applied cleanly, matched all 70 application objects and both linked Lua programs, and reproduced all ten script outputs.
