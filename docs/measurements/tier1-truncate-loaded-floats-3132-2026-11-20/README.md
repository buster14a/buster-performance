# Truncating loaded floats on x86-64

[Compiler PR #3132](https://github.com/buster14a/buster/pull/3132) at `8ed4c7e92b01a48e31d84740ae0befff151a6b31` uses [#3120](https://github.com/buster14a/buster/pull/3120) at `cfaff628dca5f82e7bd35a8b855f4f7795e8b840` as its parent. Both were built in Release for the Zen 5 instruction set. Local execution used a Ryzen 9 7940HS. Clang 23.1.4 built each oracle.

Tier 1 now folds a movable float or double load into its truncating conversion to signed 32-bit, signed 64-bit or unsigned 32-bit integer. The unsigned case uses the existing signed 64-bit conversion and takes the low 32 bits. A volatile input still emits a separate load. The selection fixture checks the actual base, index, four scales and negative displacement for all ten conversion directions in this stack.

A rolled float-to-int loop shrank from 29 to 25 bytes and its eight-way version from 221 to 178. Across six conversions and four link placements on a Ryzen 9 7940HS, the rolled loops retired about 14% fewer instructions and the unrolled loops about 18% fewer. All 24 unrolled clean-register cycle medians improved by 1.33–3.78%. All 24 with dirty upper registers improved by 4.19–6.99%. The rolled timings varied by placement. These are seven paired comparisons per case after one warm-up, with 1,536 measured processes including warm-ups.

For each of four target architectures, the parent, candidate and Clang 23.1.4 matched on 893,440 defined-input checks. Both Buster binaries additionally matched the explicit hardware result and flags on 2,752,512 checks per architecture, including NaNs, out-of-range values, unaligned inputs, MXCSR settings, and the delivered exception from an unmasked signaling NaN or inaccessible operand. The native emission, selection, pipeline and schedule suites passed.

Of 1,336 musl objects, only exp10 and exp10f changed, each by eight fewer text bytes. Both Buster builds matched Clang on all 65,536 linked exp10/exp10f output-bit and flag observations. Four SQLite date functions shrank by 32 bytes in aggregate. A date-query workload returned the same results and retired 0.021% fewer instructions across four placements. Its cycle results were mixed.

Part of #2829, based on #3120. Four indexed conversion forms still need direct Zen 5 cost calibration and runtime confirmation. The other four memory forms already have entries.
