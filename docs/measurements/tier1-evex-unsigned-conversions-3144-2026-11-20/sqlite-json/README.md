# SQLite JSON5 integers outside the signed 64-bit range

An actual SQLite JSON5 hexadecimal literal can exercise the unsigned 64-bit to double conversion in `jsonReturnFromBlob`. The [prepared query](query.c) feeds 2,048 positive and negative literals to `json_each`, either as text or as precomputed JSONB. Small integers provide a control. A separately instrumented build counted exactly 8,192 entries to the conversion with large values and zero with small values across four complete scans. All [64 correctness comparisons](checks.tsv) matched across Clang, instrumented Clang, and the two uninstrumented Buster builds at four placements.

On the local Ryzen 9 7940HS the uninstrumented JSONB query with large integers retired 0.811% fewer instructions. Its seven-pair cycle medians fell 1.05–1.85% across all four placements. Individual pairs varied in both directions. Text input retired 0.688% fewer instructions, with cycle medians from −2.72% to +0.14%. Small integers gave matching instruction counts within measurement noise. The [paired results](paired.tsv) include the full range per placement. The [256 observations](counters.tsv.gz) include warm-up rounds, and the [program identities](programs.tsv) record the source hash, engine hash, function location and executable. The measurement uses the same parent and PR compiler objects as the [five SQLite speedtest1 workloads](../sqlite/checks.tsv).
