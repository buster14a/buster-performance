# Long-double constants in Tier 1

[PR #3134](https://github.com/buster14a/buster/pull/3134) at `b437ac27b843f411646a3e05744f751a07b127ae` was compared to `78851ffc6604386c0fb25472af53c107ec2a2be3`. The reference compiler was Clang 23.1.4. The Buster compilers were built in Release and generated code for the requested target instruction sets. The direct hardware observations here used a Ryzen 9 7940HS.

For a Tier 1 long-double constant that is exactly a finite normal binary32 value or a signed zero, the CFG emitter now writes the private home with one 32-bit integer store. Arithmetic, comparison, return, phi edges, and stack arguments load it as binary32 at their original x87 waiting instruction. External objects and ABI arguments still receive all ten significant bytes. Every other constant keeps its original representation, including values that would be subnormal at the narrower precision.

A Ryzen 9 7940HS local run used eight measured parent/candidate pairs at each of four fixed link placements, after a warm-up. The affine loop shrank from 174 to 137 bytes and used 52.93–53.07% fewer cycles. The polynomial shrank from 325 to 253 bytes and used 33.35–33.95% fewer cycles. The recurrence shrank from 239 to 209 bytes and used 26.10–26.34% fewer cycles. The extended-precision control kept its 174 bytes and its cycle medians were within 0.08%. These are generated-program results. Direct Ryzen 7 9700X confirmation is pending.

The 194-constant oracle covers signs, exponent endpoints and neighbors, extra significand bits, phi choices, arguments, arithmetic and comparisons. At each of four target architectures, default and post-scheduled Buster matched the parent on all 135,024 observations of the ten result bytes, exception flags, control word, TOP and stack tags. Clang produced the same result bytes. The flag comparison also preserves the parent's distinction from Clang for constants such as 2^-149 whose narrower load sets the denormal flag. The existing pending-unmasked-exception fixture delivered SIGFPE after the volatile store in both tiers and the post-scheduled build. New decoded-object fixtures check the exact narrow and full-width loads.

Across all 1,336 frozen musl objects, 15 changed and every one got smaller, saving 1,351 text bytes. Linking the complete 300-member math and complex archive and exercising twelve long-double entry points produced 294,912 observations under twelve x87 modes. Parent and candidate matched on every result, flag and exponent. Both have the same pre-existing differences from Clang-built musl. The Tier 1 wide, emission, pipeline and schedule suites passed.
