# Unpublished cursor-hint experiment

On top of #3135, a local prototype tried the previous record's location before searching either side of it. It preserved the lower-bound semantics for bindings and upper-bound semantics for regions, including non-monotone origins. The separately instrumented baseline generated byte-identical objects for the three [census inputs](counts.tsv). A zero-sized source set is counted in the same-position column if its previous cursor was also zero.

Across eight alternating local pairs, SQLite debug compilation retired 0.034% fewer instructions and the Lua VM retired 0.081% more. Cycle changes varied across pairs. The complete [process measurements](processes.tsv) include the object hashes. The implementation was left out of the PRs.
