This is a bounded confirmation of the raw +2.17% median in the owner's five-round `h64x3.c` forced-two-lane screen.
It reuses the verified owner binaries from `merge2` (Buster `06bda160`, source-equivalent to `db1937c`) and `merge3`

## Fixed protocol and execution

`expected.json`, `plan.tsv` and `scripts/` were prepared before execution. There are 21 baseline/candidate pairs and
21 same-baseline A/A pairs, interleaved by round. AB/BA order and the A/A label order reverse on alternate rounds.
All 84 processes read only the original generated `h64x3.c`, with `--every-lane --lanes 2`, 24 passes (the six
reading orders), the frozen corpus options and `--cpus 2,0,1,3,4,5,6,7`. The two binary snapshots and input copy were
made under the shared lock and verified against their predeclared hashes. No binary was rebuilt for this confirmation.

The controller takes one fresh `~/buster-fast-bench/exclusive.sh` hold with `EXCLUSIVE_OWNER`, `EXCLUSIVE_TITLE`
and `EXCLUSIVE_LINK` set. One outer 110-second timeout plus a five-second kill grace bounds the entire controller
and its child process group. There are no nested timeouts or detached child sessions. Queue, acquired, end-before-
unlock and returned-after-unlock times are retained, together with the actual shared owner record. After waiting
behind PR #695 CI, the controller ran from 15:09:46.973068Z to 15:09:54.899238Z (7.926 seconds by the monotonic clock),
and returned after unlocking at 15:09:54.904657Z. All 84 processes, the controller and the wrapper exited zero.

Before/after snapshots verify both immutable binaries, the generated source, pinned predefines, all 778 frozen
headers, both 509-file source manifests, CPU availability and actual governors. CPU 2 has the performance governor
and energy preference; CPUs 0, 1 and 3–7 have powersave and `balance_performance`. The native host is the same Ryzen
7 9700X. `owner-post-screen-identities.json` is separately labelled: it was captured read-only after the original
screen, not contemporaneously with those earlier trials. The fresh confirmation's snapshots are `before-identities.json`

## Limits and provenance

This screen covers one affected generated unit and forced two-lane execution on these immutable artifacts and this
host. Same-binary A/A measures process/run variation, not variation between separate builds or code placements.
The mixed signs and ranges do not establish universal neutrality, a performance gain, or any whole-compilation or
retained-RSS improvement. No additional SQLite run or full 43-unit grid was performed. The other 42 units' complete
part orders were independently unchanged; their old timings remain attached to their original revisions.

The Buster source/input manifests and binary hashes bound applicability. Later source or integration revisions are
not newly timed by this record. `maxrss_kib` is each process's resource counter, not an RSS-retention series across
units. The original 54a3b6da-versus-cd9c5c9b A2/B2/CT2 campaign remains a separate frozen result.

The controllers and analysis are original project material. `inputs/h64x3.c` is the original generated fixture whose
bytes match this record's existing generator/manifest. External corpus headers and SQLite are not incorporated.
No human certification trailer is added in this performance repository.
