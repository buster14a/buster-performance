EXACT C3 CONTRACT
The new hp_normalize.c/h pure C module accepts only the two exact paired
source-manifest/qualified-normal tuples above; crossed/unknown tuples refuse.
Each candidate must independently satisfy its own actual guarded assembly and
object profile. No unseen candidate match is assumed.

Before normalization the controller still requires direct-normal full SHA to
match the qualified normal. It retains Clang output separately as checker.raw.s.
The normalizer requires the unique LOCAL FUNC check_test_action_constraints in
ordinary executable .text, size15709, relative site0xcf1, exact21-byte call /
DC C0 / fstpt / fldt preimage, exactly one precise PLT32 __floatuntixf/-4 call
relocation at the prescribed offset and no other overlapping relocation.
Absolute function address and scoped local-label IDs are derived, not assumed.
Assembly must have unique matching type/label/size/context and coherent scoped
numeric labels, one global self-FADD target and the reviewed hot-section
envelope. Unsupported label aliases, semicolon ambiguity and malformed atoms
refuse. All bounds and ELF/header/section/symbol/relocation extents are checked.

Only the proven self-FADD instruction text is replaced with explicit assembly
data directive .byte 0xdc, 0xc0. The prefix, suffix, comments and whitespace
outside that instruction span are preserved exactly. No binary is patched.
Canonical text is published separately as checker.s, with normalization.json
binding raw/canonical/object digests, paired profile and exact derived site /
preimage / replacement. The zero-padding transform consumes canonical text,
and remains byte-exact for shift0. Raw, canonical and normalization receipt
become mandatory frozen snapshot members. Resume schema is now
buster-hot-placement-c-v3; legacy ready records or missing/tampered normalization
members refuse. Existing source/tool/reference/post/snapshot checks, full
original-vs-reassembled object proof, whole normal/inside0 SHA, linked-geometry
proof and strict failure behavior remain required without waiver.
