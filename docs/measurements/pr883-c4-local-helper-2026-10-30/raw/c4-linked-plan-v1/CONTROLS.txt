C4 linked validation control plan v1

Run the unchanged 61 linked_controls.c cases separately in strict and
ASan+UBSan+leaks modes against the final immutable linked module and fixed
hp_elf80c. Do not edit the old control source. Add a separate first-party C
linked_geometry_controls.c using the old byte fixture constructors where
practical, with the included old main renamed and never invoked by the new
program. Bind every consumed source/header in an immutable dependency
manifest; record actual source pre/post compile/run checks and terminal
statuses, compiler/cores identities, flags, binary hashes and diagnostics.

Focused controls must substantiate:
 - Two/three valid disjoint outside duplicates, in normal only, variant only
   and both images over every approved shift; shuffled symbol ordering.
 - Missing keys, no unique-in-both anchor, one-image-only unique bands,
   base zero, later inconsistent unique anchors, wrong delta and underflow.
 - Expected address absent/off by one, key metadata/section mutation and
   duplicate exact VA across sections or ordinary symbol tables.
 - Invalid outside candidate: undefined/ABS/reserved, nonexec, NOBITS,
   unsupported section type, short bytes, extent overrun/address overflow.
 - Extra interior/enclosing/prefix candidates; predecessor ending exactly
   at base accepted versus one-byte overlap refused; successor beginning at
   end accepted for nonzero functions. All equal-key candidates validated.
 - Zero functions at interior/end, extra point at endpoint, duplicate/missing
   expected points, sole unique zero anchor, expected endpoint at 2^64 and
   last-byte/overflow arithmetic. Different-key aliases remain admissible.
 - Duplicates cannot bypass downstream section/full-range/byte/prefix/
   relocation width and overlap checks; output proof remains empty on every
   refusal and all complete input buffers remain unchanged.

No actual artifact comparison, new adapter compile, image invocation, remote
or real producer activity belongs to this validation. Broader complete C4
harness qualification will need its own exact plan and root disposition.
