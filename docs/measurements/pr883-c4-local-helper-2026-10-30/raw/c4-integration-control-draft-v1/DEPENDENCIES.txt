Method seam notes:
 - HpMethod.objects is a borrowed one-element path array valid for the complete
   case. No method_free is called on borrowed stack fixture storage.
 - method_prove reads synthetic input objects first, compares and serializes an
   object proof, then reads final image data and serializes a linked proof.
 - It intentionally does not prove the outer normal-image SHA/source/producer
   identity. This draft never fills those fields with an invented digest.
 - Normal/candidate labels refer only to fragment-required function membership;
   neither immutable real compiler head is an input to this control.
 - hp_linked proof names borrow ELF bytes until serialization; actual method_prove
   frees those buffers and owned proof arrays only after receipt writing.
 - Snapshot normalization membership is separate from semantic normalization.
   Nonempty synthetic placeholders are deliberately identified in source/plan.
