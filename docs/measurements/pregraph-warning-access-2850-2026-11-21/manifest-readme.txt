One row per admitted root in *-manifest.tsv.gz, keyed by TU and parser token. File and byte offset give its root spelling (macro expansions can share a position). root-op and operand-op are CheckOp numbers at Buster 84a7d3d768; records includes the root. branch identifies an internal &&, || or ?: (cold-fallback candidate absent an internal reach plan). direct is the straight-line first-statement proof (function's own opening brace immediately before the earliest token; no internal branch), whose runtime accesses can be replayed directly. Other roots with runtime accesses require the enclosing block's final evaluation or equivalent source proof. flags is ORed over the interval: READ 1, syntactic outside USE 2, syntactic WRITE 4, statement-WRITE 8, ADDRESS 16, reached first WRITE 32, and RMW write one position later 64. Loop-uses counts potential mutation token/object events for enclosing loop analysis. Comparisons counts sign-compare index candidates. Stack-subjects counts a returned local subject for the ordinary address or automatic-array decay candidate. These latter two are candidate facts, not issued diagnostics. Per-event rows carry the interval ordinal, read/write token and source object, and the three additional projections.
