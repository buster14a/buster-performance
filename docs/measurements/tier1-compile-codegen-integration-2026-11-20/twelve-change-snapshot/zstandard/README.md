# Zstandard 1.5.7 on generated code

The upstream `v1.5.7` tag resolves to `f8745da6ff1ad1e7bab384bd1f9d742439278e99`. Pinned Clang and both Buster versions built its fully threaded static library, CLI and two upstream test programs. The build selected the same `-O2 -march=znver5` setting and used Clang for the single x86 assembly unit and final links. The common non-PIE executable configuration removes the upstream `-fPIC` and Clang-only `-Qunused-arguments` compiler options in all three builds. Both upstream tests passed with seed 31771 and 160 requested iterations in all three builds. An initial no-threading configuration failed the upstream streaming test's request for two workers in all three builds.

`objects.tsv` covers 59 build objects, including 38 static library units. Buster's aggregate machine text in the measured targets changed from 1,809,378 to 1,809,330 bytes. Every library produced and decoded the same compressed bytes across four 768-KiB inputs and compression levels 1, 3, 9 and 15. Four placements of each library gave 384 verification executions. The common pinned-Clang driver compared complete buffers, including each measured result, with an independently generated Clang frame or the original input.

The 1,792 local performance observations cover compression and decompression. Across 128 comparisons the paired median instruction changes ranged from −0.0302% to −0.000016%. The cycle medians ranged from −15.70% to +5.18%, varying by workload and placement. The rows include all four layouts and the variation across six measured pairs per layout after warm-up.
