# Twelve compile-speed and generated-code changes together

The baseline is `c8b259413110b1d6f5ff9a005a1c49f48ca01e57`. The combined compiler is local merge `8a5cc1689ac9203c3f5e086f4b8503603f6ed29a`, tree `06d1915de7bb3859e94c98b0ec6901f1e95ef58e`. The [source table](source-heads.tsv) pins twelve public PR heads, their trees and the SHA-256 hashes of the two measured compilers. Measurements here use the local Ryzen 9 7940HS, the pinned Clang Release build targeting znver5, and frozen inputs. Direct combined 9700X measurements are pending.

With one lane and eight measured pairs after warm-up, SQLite Tier 1 release compilation used 2.088% fewer instructions, from 7,852,200,739 to 7,688,284,853. Its paired cycle median was −1.545% with individual changes on both sides of zero. At `-O2 -g` it used 19.506% fewer instructions and 11.822% fewer cycles, with every pair lower. The Lua VM debug compile used 28.973% fewer instructions and 22.096% fewer cycles. The normal and debug tables publish all samples and emitted object hashes.

A separate affinity-pinned scaling experiment compiled four translation units/settings on one, two and four physical cores. All 192 runs produced identical bytes within each compiler and workload. On SQLite debug builds the paired median elapsed-time reductions were 11.86%, 14.72% and 17.34%, with every pair improving at every lane count. On four cores the individual medians were 734.44 ms and 600.10 ms. The [scaling record](physical-core-scaling/) includes instructions, cycles, elapsed time and peak resident memory.

Both compilers passed the 220-program C subset, debug, pipeline, emitter, selection and inlining suites. The inherited, unenforced matched-function size target still reports a failure against Clang. The 380 matched Tier 1 functions shrank from 62,350 to 62,298 bytes while Clang produced 45,748 bytes. Each Buster version separately built its own compiler twice, with byte-identical outputs for 43 objects and the linked compiler at stages 2 and 3. Compiling identical baseline source with the two compilers changed the linked compiler's text from 50,052,067 to 50,050,467 bytes.

All 1,451 upstream SQLite Tcl scripts passed independently with Clang, Buster Tier 0 and Buster Tier 1. Their recorded assertion totals were 1,031,366, 1,031,372 and 1,031,345, with zero errors. Only the randomized crash.test script differed in assertion count. The [full script ledger](sqlite-full/) gives all per-script results and executable hashes. The inputs used the standard full permutation at a soft open-file limit of 1,024.

The [SQLite speedtest1](sqlite-speedtest1/) and [Zstandard 1.5.7](zstandard/) results measure generated application code. They include Clang correctness controls, exact program identities and four code placements. Across both applications the candidate generally retired slightly fewer instructions. Changes in cycles varied considerably with layout.
