# Window storage and the template lookup on the frozen node streams

The SQLite sweep after 200 ms of scalar work fell from 22.30 to 20.80 cycles per taken node when the expansion scratch arrays were reused by window. Repeated SQLite stayed at 16.40 and musl at 21.60. With a single gathered template row and expression-boundary alignment, musl reached 21.10 repeated and 21.20 after scalar work. Both changes emit all entries taken by the scalar reference. The 20-cycle gate remains open.

| Change | SQLite repeated / after scalar | musl repeated / after scalar |
| --- | ---: | ---: |
| Original full-coverage displacement lookup, in the window-storage comparison | 16.35 / 22.30 | 21.55 / 22.10 |
| Reuse the expansion scratch by window | 16.40 / 20.80 | 21.60 / 21.95 |
| Verify and decode one gathered template row | 15.65 / 20.95 | 21.05 / 21.90 |
| Same row, end windows on nearby aligned complete expressions | 15.55 / 20.95 | 21.10 / 21.20 |

The single-row lookup uses a collision-free seed per hash prefix to address a row. The address provides the high bits of the transformed key. The row checks the remaining key bits and supplies the template ID, count and early-output flag. Lookup-table construction is outside the interval, as in the [initial experiment](../README.md). Choosing window boundaries and all scratch operations are timed.

Six comparisons include 432 processes on the locked Ryzen 7 9700X CPU 2. Every process checked scalar and experimental roots and emitted entries. A process ran seven passes, with three symmetric rounds per corpus and temperature and two processes per mode per round. Table cells are medians of round means. Each comparison has a contemporaneous control. The paired table includes every variant and the range across rounds, including the regressions from packed inputs, compact stores, two candidate lookup banks, context-to-key fusion, and separating contiguous payload runs. Both streams and their leaf facts are frozen, and the ordinary compiler's costs are measured separately.

See the [paired metrics](paired.tsv), [individual processes](samples.tsv), [native logs](native-receipts.tar.xz), and [source fingerprints](sources.tsv). Run the scratch-storage generator first, then the packed, row, two-bank and single-row generators. The cohort, window, fused and payload-run generators use those outputs. The six comparison scripts contain the exact compiler and timing commands.
