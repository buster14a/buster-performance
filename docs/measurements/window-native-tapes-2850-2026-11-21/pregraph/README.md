# Producing native tapes before the ordinary expression graph

The prototype selects complete return and discarded expressions from their parser roles, declarations, preprocessor warning policy and independently checked postorder records. It computes the warning tests and context rules before the ordinary reader emits each chunk. For an accepted expression, the row sweeps produce kinds, classes, 64-bit payloads and a call table while the chunk is still independent of its eventual graph-node numbers. Binding to node numbers happens later, solely so ordinary native lowering can check the already saved tape. The [eligibility study](https://github.com/buster14a/buster-performance/tree/d1ed9acdefd5ab27a1be307281f80e13dff1d486/docs/measurements/pregraph-warning-admission-2850-2026-11-21) describes its treatment of warning events, floating context, tracked statements and call declarations.

Source selection and the row emitter each have their own refusal rules. Some roots belong to code the final program never selects, and the ordinary census compares the roots its lowerer pops. Frozen SQLite produced 133,699 entries in source-completed tapes. The native oracle reached 133,611. Its checks cover the 684 global-symbol entries, 211 variadic calls, and the complete per-call scalar argument class and target tables among those compared. For labels and temporary locals the native comparator still uses the ordinary machine’s side tables. Source token reproduction and graph replacement in real compiles are separate work. The compiler-self input uses the unchanged source at 84a7d3d76.

All four inputs also passed with `-Wall -Wextra` and with `-Weverything -Wno-c++-compat`. SQLite retained 55,079 and 54,793 compared native entries under those two policies. An earlier diagnostic hook only prepared C's inputs and left X's type and payload columns stale. Running that omission control on the same binary produced 22,345 mismatched SQLite roots. Flipping the first class in each nonempty source-built tape produced 26,291 native differences. An invalid callee symbol or reversed variadic flag each produced 6,991, and flipping the first passed argument's class when present produced 6,912.
