# Removing the checked operands of short-circuit conditions

The experimental compiler derives condition tapes from source, with the post-numbering reference disabled for the entire translation unit. Before the ordinary graph writer reaches a closed `&&` or `||` operand, it checks the source actions, both unknown runtime values, the individual warning tests, and the native row and label forms. It substitutes one independently typed summary for the operand’s graph. The controlling branch remains the destination owner. Its real lowering takes the source row’s target and publishes the internal labels at their recorded positions.

Ordinary frozen SQLite removed **3,636 graph nodes** across 434 conditions. Every condition reached the required native emitter, which used 754 external branch targets and published 167 internal labels. The source tapes contained 7,471 rows. All 319,987 surviving graph nodes and 261,159 operand edges remained identical under renumbering. Buster’s own source removed 3,597 graph nodes over 446 operands. Exactly 172 of those operands reached the ordinary native writer. The debug compiles reproduced those counts. In this experiment `-Wall -Wextra` retained the original graphs on all four corpora. [Graph and branch counts](reach.tsv)

Across SQLite, 34 Lua units, 1,336 musl units and Buster itself, every one of 4,116 fresh process pairs agreed in the final native columns, ABI classifications, complete ELF, diagnostics, stdout and status. The graph oracle checked each retained edge in every changed unit, and checked that the native writer took exactly the selected conditions reached in the full-graph control. A separate 620-case matrix covered diagnostics, pragmas, constant and unevaluated arms, invalid names, updates, member loads, and loops. All pairs matched, including 161 rejected compiles. [Corpus results](corpus.tsv) · [Diagnostic results](warning-policy.tsv)

An independent Clang program called seven conditions over 3,120 combinations. It passed null pointers on the short-circuited paths. Both ordinary and debug Buster objects returned Clang’s checksum 15551088150384210005 with seven required source-native uses. Reversing branch sense changed the checksum to 11149638328258398635. Removing the required consumer or shifting an internal label prevented object emission. [Execution controls](execution.tsv)

The experiment uses Buster source `84a7d3d76891d6c393497e62e6aff38f2b162fc2`. The [complete patch, per-unit evidence, graph checker, and independent fixtures](source-and-oracles.tar.gz) include the implementation and comparison commands.
