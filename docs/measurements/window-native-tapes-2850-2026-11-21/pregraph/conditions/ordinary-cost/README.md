# What the source-condition producer costs in a fresh ordinary compile

These are local Ryzen 9 7940HS measurements of frozen SQLite with a Release compiler. The source pin is `84a7d3d76891d6c393497e62e6aff38f2b162fc2`. Each compiler has its mode compiled in. Each run starts a new process and writes a real relocatable object. PMU measurements use symmetric orders, with two observations per mode per round. The wall series times process start through exit independently, rotating and reversing mode order. The issue’s 9700X throughput result uses a different machine and revision. [All paired PMU deltas](paired.tsv) · [Independent wall series](fresh-wall.tsv)

Building the first straight-condition producer added **453.69 million retired user instructions** against the source-disabled binary. Consuming its rows during real lowering saved 3.07 million of those instructions. Both variants kept the ordinary graph. Filtering typed records to condition subtrees reduced the producer’s cost to +325.91 million instructions, with all 23,112 real native entry calls still exercised. The diagnostic breakpoint counted actual typed-entry emissions on separate runs of the same binaries. [Coverage and artifact identities](coverage.tsv)

Restricting discovery to actions belonging to a complete closing parser token cut the cost to +168.10 million instructions. This producer delivered 16,251 native entries on SQLite and all 17 on the fixture. A preceding experiment that considered only the last expression before the closing parser token missed forwarding actions and delivered 3,064 entries on SQLite and zero on the fixture. Removing the diagnostic second execution of the lean front preserved all 16,251 SQLite entries and reduced the total premium to **147.97 million instructions**. Its paired fresh-process wall was **38.71 ms slower** than source-disabled (+29.68 to +45.02 ms). These are graph-retaining runs. The graph-removal experiments have separate correctness results. [Short-circuit graph results](../short-circuit-graphs/README.md)

Every measured source variant passed separate equality checks on the 2,061,200-byte object, the 57,094,544-byte checked-graph oracle and the 4,121,401-byte native oracle. Unit-sized state for the source implementation and the ordinary checker still coexist. Three fresh cycle profiles per image identify the producer, its front and the ordinary work that still runs.
