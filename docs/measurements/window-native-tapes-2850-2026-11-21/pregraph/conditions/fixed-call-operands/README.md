# Fixed-ABI call predicates before graph construction

The compiler can now replace a fixed-prototype call predicate from its source tokens before ordinary graph numbering. On frozen SQLite, the producer removes 1,315 graph nodes across 296 predicates. The lowerer emits all 296 source tapes. Across the four workloads, ordinary compilation removes 3,709 nodes at 709 predicates and consumes 457 tapes. The other 252 predicates have no matching source root requested by ordinary lowering. Debug builds give the same counts. Warning builds keep the original graph. [Per-workload counts](corpus.tsv)

The first implementation preserved every measured ELF and native row but changed the identifiers of 5,061 surviving SQLite conversion/member records and 10 values. Skipping the function designator also skipped an insertion into the canonical pointer-type table. Looking up the pointer type in the original graph order restores those fields. Restricting admission to pointer types already present would cover 99 SQLite predicates and 441 nodes. The ordered insertion covers 296 predicates and leaves all 322,308 surviving records and 263,480 operand edges identical after renumbering.

All 4,116 ordinary, debug and warning workload comparisons and nine fixture comparisons match the original path and the source producer that retains the graph. The comparison covers exit status, stdout, diagnostics, object bytes, native instruction and ABI tables, and each surviving graph record and edge. The native witness was absent in all three modes for 34 units that emitted no witnessed body. The declaration/policy matrix matched 208 cases. The independently linked fixture invoked four functions for each of 525 input pairs and matched both Clang checksums and all three call counters in all three modes.
