# Scalar comparison rows in the ordinary expression reader

Two variants recognize direct integer comparisons using facts already present during the expression walk. Both proposed 2,499 SQLite positions, published 1,352 comparison rows and produced the reference ELF. In Buster's own translation unit, 40 of 1,345 proposals qualified. One variant records candidate positions in a separate bitmap. The other adds a bit to the existing visit byte and extracts it in the postorder gather. [Native coverage](native-coverage.tsv)

Five symmetric paired rounds on the locked Ryzen 7 9700X included separate PMU and wall observations. For SQLite the bitmap variant retired 3.54 million fewer user instructions against its disabled mode, but added 3.34 total cycles/token and 0.543 ms, each in all five rounds. Reusing the visit byte added 3.77 total cycles/token in all five rounds. Its median wall change was −0.139 ms with four faster rounds. For the self-compile the visit variant added 2.43 cycles/token and 0.988 ms. The stage report, diagnostic comparisons, compiler revisions, binary hashes, experiment scripts and per-observation objects identify each treatment. Both development compilers passed their complete registered checker and all 4,116 file and policy comparisons against the parent. The bitmap variant's native timings precede a guard for scanner-only clients that omit the preprocessor. The measured ordinary compilation path supplies that preprocessor. The correctness archive contains the final versions of both patches, full checker logs, and file-by-file object and diagnostic hashes. [Correctness checks and sources](correctness.tar.gz)
