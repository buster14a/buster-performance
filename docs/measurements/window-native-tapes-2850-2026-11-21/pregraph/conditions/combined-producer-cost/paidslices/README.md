# Charging the producer for the controlling expression

Restricting each source window to the actions in its controlling expression removed 13,744 of SQLite’s 323,623 checker nodes and 524 of 34,220 argument records. The remaining 309,879 nodes produced the same 4,512,453 native bytes as the ordinary path. Across three locked Ryzen 7 9700X rounds, enabling the producer cost 11.897 ms and 68.72 million user instructions compared with disabling it in the same executable. All three rounds were slower. Against the unmodified public parent, the median paired cost was 11.806 ms. The Step 2 budget remains open.

A condition’s postorder subtree can include its statement bodies. The source path retains the actions at or before the controlling close token, checks their eligibility, and joins consecutive selected positions. The original graph and lowering handle the other actions. The source archive includes the full patch against `d335da08d` and the three-way runner. Plain compiler, producer disabled, and producer enabled matched on the SQLite object and warning output.

Each row in [the timing table](sqlite/paired.tsv) compares symmetric round means. The public parent had especially variable page faults during the PMU series, ranging tens of thousands apart. Its total-cycle difference fluctuated in direction. The same-binary comparison recorded 206.5–208 additional faults with the producer enabled and higher cycles, elapsed time, and instructions in every round. PMU and elapsed came from separate processes.

The [local oracle archive](local-oracles.tar.xz) contains 4,116 matching per-unit object, exit status, stdout and diagnostic comparisons across SQLite, the Buster compiler, Lua and musl. The directed fixture combines 45 predicates and nested bodies, tests 4,096 inputs under each of four compiler policies, and compares the execution trace and return value with Clang. Mutating an admitted body changed the result. Source graph and native hashes, the fixture, and its generator are included.
