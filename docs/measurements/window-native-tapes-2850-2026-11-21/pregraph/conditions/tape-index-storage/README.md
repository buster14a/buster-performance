# Storage cost of the native tape index

Two alternatives to clearing the direct index were tested against the same [screened source producer](../paid-graph-removal/). A two-level table allocates blocks of 64 entries on demand. The direct alternative keeps the index and several related tables in their original locations, uses zero as the empty summary index, and skips an explicit clear only when the caller owns the fresh output arena and the allocation begins in untouched space. A reused arena takes the explicit initialization path. All three builds matched on the complete SQLite checker graph, native witness, ELF, stdout and diagnostics. [Artifact and build identities](checks.tsv)

On the local Ryzen 9 7940HS the two-level index removed a median 2,686 minor faults but added 2.41 million user instructions per compile. Keeping the direct index with the ownership check removed 2,860 faults and 0.064 million user instructions. Its median total-cycle change was −26.31 million. Five adjacent symmetric rounds each ran both variants twice. These results concern memory placement inside the source producer.
