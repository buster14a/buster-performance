# Source conditions and their ordinary native entries

The prototype builds a condition's checked expression and native entries at reader time, from source records and the current window's type view. The parser distinguishes a trailing do/while from an if or while, so the producer knows the branch sense. Each operand's postorder distance identifies the consumer that emits its conversions and tests. A call places its ABI conversion at the callee's token. Named and dereferenced update destinations inherit the updating operator's token.

All reached native entry kinds, classes, values and resolved branch destinations matched the late ordinary lowering. SQLite's complete source comparison, including the previously qualified returns and discarded expressions, now reaches 38,731 roots, 233,906 entries, 10,082 calls and 24,586 call arguments. Each corpus uses its actual reached roots as the comparison denominator. The source-coordinate comparison joins the source candidates to the ordinary inventory after the chunk. A separate consumer splices supported plain scalar conditions directly into actual Tier 0 lowering. It checks the current body's slot and storage class, resolves globals and VLA addresses, emits the source entries, and leaves the statement's branch to its existing lowerer. Conditions requiring calls, pointer arithmetic or short-circuit expansion use ordinary lowering in this revision. On SQLite the consumer took 5,008 conditions in the default object and 5,008 in the debug object, and 1,723 under Wall/Wextra. Ordinary, debug and warning compiles for all 1,372 translation units yielded **4,116 paired comparisons**. Every pair emitted an object and matched its complete ELF, final native columns, checked graph, stdout, diagnostics and exit status. The debug comparisons include every native entry's source token as well as the ELF's DWARF. The graph still exists for these comparisons. A differential control changing the branch sense broke 1,483 reached SQLite native tapes and six in the seven-condition fixture. A control assigning converted call arguments the closing parenthesis kept all native values identical but changed 22 SQLite source entries and 12 compiler entries. The runtime fixture agreed with separately compiled Clang on all 11,760 input combinations under the ordinary, debug and Wall/Wextra configurations, both with the consumer active and using ordinary lowering. For this runtime fixture the consumer took three conditions under the ordinary and debug policies. Wall/Wextra declined all of them. The comparison covers source and execution correctness. It supplies no wall-time or PMU result for an uninstrumented compile.
