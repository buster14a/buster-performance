# Source-derived short circuits, branch labels and pointer strides

The reader records each internal short-circuit label's preorder ordinal and relative native-entry position. The ordinary body writer reserves that many labels and ties the condition's external destination to the pending statement branch. Straight pointer indexing emits a U64 pointer add with the stride encoded by the source type. Missing proof, unsupported ABI or class, and other expression forms defer to the existing compiler. The complete [experiment patch](pointer-condition.patch) applies to Buster `84a7d3d76891d6c393497e62e6aff38f2b162fc2`.

On frozen SQLite this raises the number of conditions emitted directly from source tapes from 5,008 to 9,369 in a real ordinary object. They include 1,120 conditions using the pending branch and 340 source-placed internal labels. The warning policy admits 3,156. Across SQLite, Lua, musl and the compiler, all 4,116 pairs of fresh ordinary, debug and Wall/Wextra compiles agreed on exit, stdout, diagnostic text, full ELF, the checked graph, and every column and source token of the final native stream. These runs retain the ordinary graph and disable the late reference join. [Per-corpus results](object-driver.tsv) · [Per-unit hashes and runtime inputs](raw-checks.tar.xz)

The independent reference join compares each reached internal label with both the ordinary machine's ordinal and the final lowered body's actual destination. All 820 label positions agreed across the four corpora, including 491 at 464 SQLite roots. The executable fixture tests integer conditions, nested short circuits, a field and a nonconstant subscript over 36 argument combinations. Both compiler paths produced the Clang 23 result for ordinary, debug and warning runs. Changing a branch sense changed the executable result under all three policies. Changing the pointer stride changed it under ordinary and debug. The warned fixture admitted only two branch conditions and kept its original result after the stride change. Shifting an internal label by one entry failed Tier 0's stack consistency check under every policy.
