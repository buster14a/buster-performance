# Direct fixed-prototype calls inside source-derived conditions

The source producer retains the declared function type and the direct callee's object alongside the argument classes. Before writing native instructions, the consumer checks the callee's attributes, calling convention, return type, parameter types, arity and the current body's argument and call capacity. It reserves the ordinary ABI rows in source evaluation order. A function that calls a different returns-twice callee can still use the source path for an ordinary call. Direct returns-twice calls retain the established lowering. [Complete patch for compiler 84a7d3d76](abi-condition.patch)

Frozen SQLite now emits **10,185** complete conditions from the source window, including 859 direct calls, 1,786 arguments and 424 internal labels in both ordinary and debug builds. The warning build emits 3,492 conditions with 349 calls. On the three other ordinary corpora, Lua emitted 173 calls, musl emitted 307 and Buster emitted 156. The ordinary graph remains available in this experiment. The [physically reduced memory-comparison experiment](../compacted-conditions/README.md) tests a separate case.
