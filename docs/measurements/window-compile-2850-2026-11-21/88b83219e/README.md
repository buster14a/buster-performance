# Keep complete typed and static output for source-native compilation

The source-local compiler `b352534f202b8a739923cd8b5c8953f773f6a9e1` retired selected function graphs during diagnostic dumps. Their expression rows could disappear from the typed dump even when the final ELF was identical. Revision `88b83219e2ae1f5a06f074296bb14e66a885e1c2` consults the driver’s existing ownership decision before retiring any function. The driver retains ordinary graph ownership when a complete dump or attested verification is requested. [Change](implementation.patch) and [compiler identities](builds.tsv).

The comparison exercised SQLite, Buster and 35 directed sources across plain objects, typed dumps, static dumps, both dumps together, strict warning dumps, syntax checking and attested verification. 99 source/mode pairs had dump differences on the parent. The corrected compiler recorded 0 differences from the ordinary reference, including admission audits. 4/4 historical object identities matched.
