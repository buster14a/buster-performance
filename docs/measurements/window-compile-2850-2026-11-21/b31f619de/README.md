# Resuming a single semantic reader across original-source windows

The live preprocessor records declaration boundaries and the ordinary source-order reader consumes those ranges with one binding stream, type table and set of pending semantic actions. The boundary cursor limits the visit scan and defers actual end-of-unit cleanup to the real sentinel. SQLite resumed across 41 nonfinal source windows with 263,413 semantic visits. Buster resumed across 82 windows with 765,438 visits. This experiment runs the resumable reader after preprocessing. Both complete native ELF files and both warning settings matched. All 57 directed source/policy comparisons agreed. [SQLite](sqlite.stderr), [Buster](main.stderr), [source](source.patch), [commands, cases and results](native-controls.tar.gz).
