# Compaction of completed ordinary binding references

Signed candidate `d0124ae4a66858dbf2173292b0e9937f8423ad86` compares with upstream `40ae34f9d77afc42face58eff3338b7b1d1ba469` and the [source-close producer](../9487f6a8e/README.md). Once the producer settles a local variable or parameter use, its canonical event marks where the token received its final declaration and type. The final AVX-512 collector uses those marks to omit completed references before validation and publication. It still counts every binding operation.

Ordinary SQLite compacted 19,103 remaining uses from 97,600 and the Buster translation unit compacted 121,483 from 217,102. Both inputs kept their full lists with `-Wall -Wextra`. Ordinary, warning-enabled, quiet, explicit disabled attestation and scalar controls produced identical object bytes for both inputs. A separate 450-case source and binding check compared every canonical event, final declaration, final type, exit status, diagnostic and object or assembly byte. The broader suites passed 3,096 declaration controls, 4,116 frozen single-source controls and 850,926 checker assertions.

Local SQLite measurements used one reserved Ryzen 9 7940HS physical core. Each wall observation launched one compiler process directly from a monotonic-clock driver. Each PMU observation launched one compiler process under perf. An interleaved four-way series used 32 wall rounds and 16 PMU rounds. Relative to its same-binary full-list control the filtered collector reduced user instructions by 3.460 million in all 16 counter rounds. Its paired median wall difference was +1.1623 ms (14/32 faster) and its user-cycle difference was +14.523 million (7/16 lower). Relative to upstream, wall was −0.3373 ms (16/32 faster), instructions −2.958 million (16/16 lower) and cycles +26.151 million (4/16 lower). A separate baseline-versus-candidate series recorded −1.4170 ms wall (20/36 faster) and −1.087 million user cycles (6/12 lower). This candidate remained a local experiment.
