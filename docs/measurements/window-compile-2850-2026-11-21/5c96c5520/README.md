# Implicit ordinary use metadata

The candidate `5c96c5520b0399e4cb2c644fdb487d9d21e2f032` reads a bound use’s identifier key from its active declaration. It writes the source token, ordering point, operation and previous handle. The depth, visibility end and object kind follow from the operation. A missing target retains the original identifier key. Full scalar or observed alternate modes keep explicit event metadata.

GDB found the new physical slot values for 97,600 SQLite and 217,102 Buster uses. Each key, visibility end and kind differed from the explicit upstream slot. Each reconstructed whole-unit event stream, final type and declaration columns, native ELF and diagnostics matched upstream `40ae34f9d77afc42face58eff3338b7b1d1ba469`. The test of the compact wire representation also reconstructed 498 full source observations and 24 actual upstream binding-test states. These contained 6,835 unbound and 7,959 nonordinary uses in the binding-test states alone. The frontend comparisons included 450 focused source/policy cases, 856 pragma, symbol-rename, target-version and floating-point controls, 3,096 declaration controls, 4,116 frozen single-source cases and 850,926 checker assertions.

The local four-way comparison used one reserved Ryzen 9 7940HS physical core. Each elapsed observation launched a single compiler process and used Python’s monotonic clock. Each PMU observation launched one compiler process under perf. Compared with its same-binary explicit-row control, the candidate saved 1.071 million user instructions (16/16). Its paired median wall difference was +0.7376 ms (14/32 faster) and its user-cycle difference was +8.298 million (5/16 lower). Relative to upstream, the four-way median differences were +0.7018 ms (15/32 faster), −0.385 million instructions (16/16 lower) and +7.331 million cycles (6/16 lower). An independent two-arm series gave −2.7722 ms (23/36 faster) and −4.788 million cycles (8/12 lower). The local evidence did not warrant target timing.
