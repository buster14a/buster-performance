# Physically compacting ordinary fixed-prototype calls

The ordinary parser-action reader can retain the native call target, argument rows, read events and source positions when a complete statement or return calls a fixed System V prototype with up to eight simple arguments. It accepts automatic objects of the exact parameter type and small plain decimal integer literals. Its retained graph leaf replaces the original call and its designator and argument nodes. The ordinary lowering path resolves function symbols and local slots, publishes ABI descriptors, and emits the stored rows.

The pristine comparison uses Buster commit `6e9c51b9d238734468dccc03ab1b6c715449804e` with no window option. The per-graph comparison uses `--node-window` and `--node-window-calls` in the same qualification binary. Both use `--lanes 1 -c`. The default compiler leaves windowing off in debug mode. An independent debug qualification forced the exact source route on separately.

The no-mutation variant at `b5d547524` requires the function decay pointer to exist before expression checking. It admits 520 SQLite calls and removes 1,618 normal nodes. The ordered-replay variant at `e81d07a75` also records the first absent function decay of each signature and materializes its type in ordinary graph order. It admits 2,337 calls and removes 9,572 normal nodes. SQLite's compiler type table has 4,740 entries in both runs. For the integrated replay, the comparison validates every surviving checked value, operand, argument edge and conversion, the program's per-body references and object symbols, and the final native/ABI input to the assembler. `regression.patch` adds the eight-line first-use case to the normal checker test. `sql-graph-v1.json` is the actual changed survivor data from before either type-order correction.

The source-address, attribute and warning constraints have executable controls. In `mutations.tsv` exchanging two retained arguments changes both native inputs and the executable result. Removing the retained local read makes an erroneous source pass `-Werror`. Changing the function object or dropping the reference to a private function causes emission to fail. The pointer-discard fixture preserves constant-expression restrictions when the parser creates the summary. The flattened-caller fallback preserves target-feature errors caused by caller attributes.

`summary.tsv` compares actual exit status, diagnostics, object files, backend inputs and the graph. Tables ending in `.tsv.gz` store the translation-unit results. `sparse-special-*.tsv` cover mixed live/refused calls, eight argument positions, pointer results, conditional warnings and static functions under the named extra policy. Set `BUSTER_CORPUS_ROOT` and `BUSTER_COMPILER_SOURCE` as described in `corpora.sh`. Run `python3 qualify.py /path/to/compiler run.tsv --policy default focused bound generated static diagnostics physical-runtime sqlite lua musl main` for each primary policy. Run `python3 pristine.py /path/to/unmodified/compiler pristine` for the clean-parent receipts. The build patches are for Buster commit `6e9c51b9d`; the extra C test and the deliberate fault injection are relative to `e81d07a75`. The qualification binaries include optional differential output. The compiler's production behavior uses no differential output during ordinary compilation.
