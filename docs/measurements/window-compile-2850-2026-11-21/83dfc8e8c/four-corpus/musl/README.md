# musl input and measurements

One fresh process compiled 1,336 source file(s) containing 5,039,639 preprocessed tokens. Every one of 45 recorded compilation commands produced the identical [per-file object manifest](objects.tsv). The default and `-Wall -Wextra` batch invocations checked ordinary and option output on all inputs. Each input also ran alone in the enabled mode with stage counters. Its [per-source ELF and token receipts](per-source-qualification.tsv.gz) and [independent admission counts](admissions.tsv) preserve that second check.
