# Native objects from source-owned control tapes

A source function is parsed into its own check graph and checked while that graph is live. A local statement writer produces its resolved control tape and dependencies; the existing general lowerer immediately consumes that tape and the local checked stream. The translation unit keeps the canonical typed operations and named dependencies. It drops the body graph, selects symbols, resolves the saved handles and runs the normal x86 encoder and ELF writer. The general lowerer runs once for an owned body. Ordinary functions share the same translation unit.

In the complete nine-function fixture, both branches of an if/else, folded conditionals, while, do/while, for, loop exits, assignments, multiple calls and external data access compile with one reserved whole-unit graph slot and zero persistent nodes. Their 94 checked nodes use the function-local arena. Both defined and unresolved symbols, unwind information, sized branches and relocations are present in the complete byte-identical ELF. The mixed 11-function fixture retains 14 ordinary nodes for the unowned initializer and switch. Native execution, the call side-effect accumulator and the count of calls to an unreachable extern match independently compiled Clang 23.1.4 in each fixture.

On frozen SQLite, 1,218 bodies produced a local control tape and generic typed program. Ordinary selection emitted 1,212 of them. The local graphs held 41,825 of 323,623 expression nodes; 281,798 remained in the ordinary graph. The selected local functions supplied 51,414 of 381,191 typed operations (13.49%) and 1,784 per-body object dependencies. Ordinary publication resolved every target and reproduced the complete 2,061,200-byte object, SHA-256 2238999c41e256cc9c14ddbe21e379f0b3c09df25fb642b056e18b8a7ea773a0. Six referenced the same function handle, classified as external in the isolated context and defined in the unit. The normal unit publication resolves all six, as shown by the final complete object.
