# Ordinary instruction selection can reuse pre-EOF native bodies

While the original preprocessor held an active context, the compiler checked the closed prefix and emitted native fragments. The final ordinary compiler performed binding, graph construction, lowering, and normal inlining decisions. At its instruction-selection call it compared the typed body and ABI, inferred the early-to-final symbol numbering from typed uses, checked access modes and remapped relocation targets. Accepted functions reused executable bytes and unwind metadata from the prefix.

On SQLite the ordinary selection call consumed 1,614 distinct functions, 158,794 typed entries, 421,347 native bytes and 6,264 relocations. On Buster it consumed 214 functions, 27,831 entries, 80,068 bytes and 1,028 relocations. The complete ELF objects matched independently compiled local references. All four linked SQLite shell scripts matched Clang on stdout, stderr and exit, including the two scripts that exercise errors. Running the speculative prefix still duplicates frontend work.
