# Checked scalar declarator recipes from physical windows

The semantic reader used a precomputed identifier and star count to build 5,818 SQLite named declarators (883 pointer layers) and 17,110 Buster declarators (1,576 pointer layers). The ordinary type table and declarator completion rules still own ABI and diagnostics. Full SQLite and Buster ELF, default and maximum warnings and 57 forced-window language/policy observations matched ordinary.
