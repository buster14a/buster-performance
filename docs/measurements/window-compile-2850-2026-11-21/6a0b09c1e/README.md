# Tagged expression-list heads

A singleton expression list stores its node in its head. Multi-value lists tag the head and store their tail and length separately. This experiment was enabled explicitly. All 6,860 object, stdout, stderr and exit comparisons matched independent ordinary compilation, including 863 expected nonzero exits. The eight checker shards passed 850,926 assertions. Six fresh process groups per workload and three separate counter samples per arm ran on the local Ryzen 9 7940HS using matched Develop builds. The timing control is the exact parent 40ae34f9d.
