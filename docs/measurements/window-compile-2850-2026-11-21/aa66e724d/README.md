# Semantic context at external declaration close

The semantic source produces constant context and ignored-token status for each token when its containing external declaration closes. Against all facts after ordinary binding, type and constant processing, the final expression graph consumed these bytes with zero repaired context blocks and zero repaired ignored blocks on SQLite and Buster. Five of 11,190 class blocks required repair on SQLite and zero of 38,025 on Buster.
