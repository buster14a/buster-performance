# Statement control, object references, initializers and switch cases from a function's checked graph

The source-first reader reproduced every ordered control entry and referenced C object for 2,254 of SQLite's 2,674 functions. These functions produced 37,957 control entries, including 2,511 initializations, 52 switches and 753 emitted case entries. They referenced 7,251 objects summed across functions. The separate ordinary program supplied the reference. On Buster, 2,759 of 8,667 functions matched across 34,104 control entries and 9,209 summed references. Each record uses the grammar token and function-relative graph node. Initializer and case indices resolve to their declaring source tokens. Branches retain their actual ordered control destinations. [Compared records](records/) and [complete output from both producers](raw/)

The initializer comparison covers 2,592 SQLite plans with 5,277 parts and 9,525 Buster plans with 14,167 parts. It checks byte/bit offsets, widths, value bytes, source nodes, C type, conversion flags, diagnostics summary and every literal byte. The switch oracle also covers default and pruned cases. All 800 SQLite and 430 Buster case records matched their ordinary numeric bounds, owners and final control destinations. All 23 directed functions reproduced every entry, including nested and folded switches, GNU ranges, goto, _BitInt(150) cases and aggregate initializers.
