# Run the vector parser directly on its final token and tree columns

The vector grammar used the original token arrays. For each window it temporarily installed the required padding and restored the untouched suffix. A separate full-preprocessing instance compared all token, tree and traversal fields at every row. Five matched local rounds measured SQLite at 266.422 ms ordinary and 268.085 ms live (paired +2.966 ms, 2/5 lower), and Buster at 1,497.642 and 1,507.310 ms (paired +8.952 ms, 1/5 lower).

The local Ryzen 9 7940HS compiled 716,136 SQLite tokens across 42 windows and 2,433,563 Buster tokens across 83 windows. The grammar emitted 709,161 and 2,421,290 tokens respectively before the original preprocessor reached EOF. The full native object, diagnostics and exit status matched the ordinary driver under both the default and maximum warning settings. All 57 directed source/policy comparisons matched.
