# Active preprocessing from original source bytes

[Standalone reproduction commands and input identity](reproduce/README.md).

The earlier machine-locked timing rotations and paired profiles below held the lock across several child invocations. They are exploratory measurements. The subsequent structural study releases the hardware lease after every individual build, test or measured process, following the current repository scheduling rule.

The eager preprocessor completed the frozen 9,507,037-byte SQLite translation unit in 8.678 ms in a fresh process on CPU 2 of a Ryzen 7 9700X. The timer covered intern-table construction, preprocessor initialization, file input, includes, conditional evaluation, expansion and final token production. It stopped before printing, releasing the translation unit and process teardown. Stage instrumentation was disabled and expansion history was deferred, as in ordinary compilation. This corresponds to 1.096 decimal GB/s of primary source and leaves 0.829 ms for all other work within the 9.507 ms whole-compile target.

The standalone driver built with pinned Clang 23.1.4 produced the same 2,358,073 bytes as the ordinary compiler’s `-E -P` command. Their SHA-256 is `ffede5fcb477a7204a9a4e98dfe4b0ce41c955088a4ca3b83df606ca8285cfa9`. The timing series employed fresh processes, fresh compiler data structures and warm filesystem pages. ## Source-direct producers

The first producer reads physically simple ASCII lines at a live file cursor. Bit masks find token starts and ends, exact live-table checks preserve macro semantics, and accepted source publishes final token kinds, canonical names, spacing and physical locations. Failed lines leave the output position at the original byte. The second producer handles common multi-byte punctuation and preserves macro calls through immutable file contexts. The third uses ordinary SIMD tokenization and identifier refinement on a regular active tile. It publishes the plain prefix directly and retains an immutable suffix for the full macro reader. All versions run the ordinary conditional evaluator and include search. The stream accepts unseen source without seeded workload-specific names or a prior translation.

The general tile producer reached 272,550 active source rows, emitted 80,286 directly before a complex macro tail, and handled another 1,312 in its short-line decoder. It still prepared 2,903 canonical fallback fragments covering 4,798,226 bytes. Frozen preprocessing produced the same physical transcript in every arm. A fourth producer, commit `0033c0918`, processes actual directives inside each retained tile through the production dispatch table. It prepared 464 fallback fragments covering 4,835,534 bytes and reached 295,693 raw rows in 614 active tiles. It published 42,257 rows before the first hard macro in each tile, plus 1,115 from short-line decoding. Its downstream consumer receives the ordinary preprocessor token stream and canonical identifier IDs. New source identities may be interned in a different order when a disabled region does not contribute names.

An 8 KiB active tile that accepts interior phase-two splices exposed a real boundary defect on intermediate commit `19e3a425f`. A continued object macro followed by a block comment crossing the frontier detached the `+ 2` suffix from its replacement list. The eager compiler, Clang and fixed commit `d1dfcf0b4` all produce `int value=1 + 2;`. The intermediate commit produced a free-standing `+ 2` and `int value=1;`. The repair checks again that the last retained physical newline terminates a logical line when trimming a partial block comment. The fourth producer predates this interior-splice optimization. ## Repeated identifier spelling

Two alternatives use a new 2,048-entry spelling table for a large primary file, initially empty in every process. A CRC32C over the length, first eight bytes and last four bytes selects a slot. An exact length and prefix comparison suffices for short names. Longer names need exact comparison with the canonical spelling through the last byte. The table stores canonical intern IDs, including for misses handled by the original intern table. The first revision uses the dictionary in entire backslash-free refinement blocks. The second admits unaffected identifiers in marked blocks, sending marked spelling spans through ordinary trigraph, splice and UCN handling. Both passed the independent identifier suite, including 20,000 randomized inputs, 9,600 protected-page cases, 50,570 disturbed spellings and 13 real and deliberately collision-heavy files totaling 13,226,024 bytes. [Plain-block spelling results](oracles/names-check.log), [marked-span results](oracles/spans-check.log) and [collision generator](reproduce/colliding-names.py).

An independent 9700X run serialized all 716,136 output records in order, including each kind, flags, absolute source location, non-name value and canonical spelling of every identifier or keyword. All eight streams matched exactly across the eager baseline, prior inactive cursor, directive-aware active tiles and splice-corrected active tiles, in deferred and materialized history modes. The serialized stream's SHA-256 was `ae672d917060281beb9f1bd4d858cd2eb51f9b802fce7407c3d1622c12611876`. In materialized mode eager and the directive producer both recorded 55,572 expansion entries and 88,426 history runs. The oracle compares emitted token provenance and separately records history counts. [Normalizer](reproduce/rows.c) and [native hashes and counts](measurements/active-source-origins.tar.gz).

The source-first checker can read `pp.output` directly. The eager baseline produces this stream with canonical identifier identities and physical locations in the existing representation. A detached checker must retain the preprocessor's canonical table and file/range storage for as long as any emitted token or diagnostic refers to them. Direct output from a live source tile has this same consumer contract.

A third design probes eight short source spellings together. Masked vector gathers read at most eight bytes per eligible name and compare complete spelling plus length. Misses compact into a dense stream for the original pipelined 64-name lookup, preserving source order. The original spelling and canonical bytes must agree before their ID can enter the local table. Entire raw files can contain backslashes, UCNs and trigraphs. First construction exposed a 256-row tail-mask mistake in the independent full-file intern oracle. The signed revision saturates the live eight-lane mask at eight rows. [Corrected full-file and protected-page comparisons](oracles/batches-check.log).
