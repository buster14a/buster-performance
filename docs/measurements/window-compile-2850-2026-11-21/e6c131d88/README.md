# Source-local static objects

The source checker retains the ordinary path for diagnostic-sensitive initializers. Local validation reproduced status, stdout, diagnostics and every emitted ELF in 33 standard and 76 adversarial comparisons. Fourteen Buster tables now supply 1,090,424 bytes and 62,620 addresses. A reference fixture forces all sixteen candidate symbols into the object and also matches. SQLite has no structurally eligible table.
