# Final static object bytes and source relocations from checked windows

The source reader runs the existing C initializer planner and data encoder while each row's graph and checked values are live. It produces every byte of the row, including alignment padding and overwritten places, along with ordered relocation offsets, source object identities and signed addends. It releases the row before checking its successor. Three tables already materialized by Buster's literal reader retain that separate path.

On the frozen Buster source, five of the 16 newly encoded tables have ELF symbols. All five matched their ordinary object byte ranges and relocation targets across 10,868 rows, 392,792 bytes and 8,469 relocations. One of these is the 334,320-byte x86 instruction table with 8,358 string references. An additional source took the addresses of all 16 tables to force them into the final object. All 24,476 rows, 1,107,440 bytes and 63,290 relocations then matched. Eight generated 384-row inputs independently exercised floating fields, nested arrays and structs, integers, omissions, designators, and references to strings and functions. [Ordinary input](tables/main.elf.tsv), [all 16 forced symbols](tables/forced.elf.tsv), [complete fixture results](tables/) and [reference ELF hashes](elf.tsv)

The independent verifier decodes ELF64 sections, symbols and RELA entries. It checks byte ranges, relocation widths, offsets, signs, literal contents and the section-relative destination of named symbols. Its input comprises the live source producer's raw rows and a separately emitted ordinary ELF. The source process ends after this materialization. Full integrated object emission and ordinary compile time require separate evidence. [ELF verifier](verify-elf.py), [all raw transcripts](raw/), [forced-reference source](all-tables.c), [source changes](source.patch) and [provenance](provenance.tsv)

To reproduce, apply source.patch and build. Compile the frozen source with ordinary arguments to obtain the reference object. Run the same compiler and source arguments with BUSTER_SOURCE_STATIC_DATA, BUSTER_STATIC_ROW_WINDOWS, BUSTER_CHECK_BODY_SOURCE_ONLY, BUSTER_CHECK_BODY_ADMIT_ALL and BUSTER_CHECK_SOURCE_DECLARATIONS all set to 1, saving stderr. Pass that log, reference object and output TSV to verify-elf.py. Compile all-tables.c with the frozen Buster source directory on its include path to reproduce the forced-symbol comparison.
