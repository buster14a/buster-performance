# Independently judged postfix updates on plain int locals

The assignment-option prototype recognizes an identifier immediately followed by postfix increment or decrement. It checks that the name belongs to the operator and that its ordinary parent discards the result. Complete block statements and the step of a for loop qualify. The compiler judges the local and update with the existing pregraph T rules and publishes the checked int plus five native entries, each with its parser source token. The original enclosing discard remains in place, including when the loop body's actions occur between the update and the closing parenthesis. An update reads the old value before it writes the local. A discarded update counts as a write for set-but-unused diagnostics.
