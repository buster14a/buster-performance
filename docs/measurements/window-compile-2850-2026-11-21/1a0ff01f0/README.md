# Candidate function sites from declaration and use traversals

Source scopes supplied 34,853 SQLite and 35,642 Buster candidate site coordinates. The accepted physical root sets equaled the dense scan. Local SQLite admission measured 13.064 ms with these sites versus 12.293 ms with the dense scan. [Source, measurements and verification](evidence.tar.xz).
