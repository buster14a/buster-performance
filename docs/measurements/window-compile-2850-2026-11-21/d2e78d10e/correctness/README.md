# Warning graph source qualification

The verified postorder-tree evaluation pass checks the roots whose evaluation was cleared while initializing the same 64-node block. Every subtree edge points to a lower ID. At that point, every child that a cleared root visits has already been initialized. Shared and forward edges still take the original graph algorithm. The reference revision is 9be958d5c61538562177a788a76c8c23dead9694, and the candidate is d2e78d10e4d37f8d3c57e637b6a00c1eae697aca.

GDB read the exact cached root bitmap and the original evaluation bytes after static selection and control-flow analysis in native 9be Release. SQLite visited 58,732 roots and found 42 cleared among 323,623 graph nodes. Buster main visited 406,075 roots and found 21 cleared among 1,409,696 nodes. After all warning reach and operand masks, the full reference/candidate evaluation columns hashed identically. Default SQLite contained 1,099 unevaluated nodes and default Buster main contained 35,427. The focused source includes a shared-edge fallback graph and a tree under changing pragma policies. The guarded randomized parent fixture compares every byte against evaluation propagated independently in reverse node order across block tails, branch fan-out and extreme root densities.

These are source correctness measurements. The 9700X Release binaries were copied unchanged to a separate AVX-512 host to execute the checks and capture live columns. The exact frozen performance inputs and their native outputs are recorded separately. File paths and system header versions affect the local ELF and diagnostic receipts.

For the Python CLI harness, set WARNING_QA_SOURCE to the Buster checkout, WARNING_QA_CORPUS to a directory containing sqlite/sqlite3.c and inputs/lua-5.4.8/src/lvm.c, and WARNING_QA_PREDEFINES to the Clang-generated host predefines. The compiler paths are its first two arguments. The --facts and --literal modes invoke GDB to read the respective complete columns. ONLY_CASE and ONLY_POLICY restrict the run. The fixture standalone checks in this directory compare default, scalar, deferred (three lanes), syntax, debug and opted-in node-window behavior.
