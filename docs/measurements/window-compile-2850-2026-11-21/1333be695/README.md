# Parse and traverse completed source declarations during preprocessing

On SQLite the experimental source reader published 709,161 of 716,136 grammar rows before the preprocessor reached end of input. The 41 live windows and the final tail agreed with the ordinary whole-unit parser on every token's kind, identifier, flags, physical output position, role, depth and parent. Buster produced 2,421,290 of its 2,433,563 rows before preprocessing ended, across 82 live windows. It consumed 2,433,922 PP output rows including its pragmas. Its final tree and seven input/tree columns also matched at every position. The source callback only receives finalized, keyword-resolved ranges. File-level typedef and tag state persists across committed declarations. [SQLite](forest/sqlite.tsv), [Buster](forest/main.tsv), [source parser](forest/live.c).

Computing postorder, postorder positions, subtree ends, first children, sibling links and subtree sizes while each window was live also matched all six whole-unit traversal columns, across every row on both corpora. [SQLite](columns/sqlite.tsv), [Buster](columns/main.tsv), [derivation and checks](columns/live.c).

The AVX-512 parser's K1–K6 and ordinary fallback kernels ran on the same live windows, seeded with the visible file-scope typedef meanings captured by the scalar source parser. All 42 SQLite and 83 Buster window results were usable. Both independent checks were exact, against the scalar window tree and against the ordinary complete parse. This experiment still uses the source scalar reader to supply the starting file-scope state. [SQLite](vector-grammar/sqlite.tsv), [Buster](vector-grammar/main.tsv), [kernel driver](vector-grammar/live.c).

The directed scope suite includes cross-window typedefs and tags, old-style definitions, function pointers, includes and pragma packing. All fifteen accepted ordinary cases matched exactly on every row. Two ordinary parse errors and a preprocessing failure were retained as controls. The source reader declined the history-dependent C23 attribute example and left that case for the ordinary parser. [Case generator](edge-fixtures.py), [results](edge-results.tsv).

To reproduce, apply [the source-range callback and file-scope patch](source.patch) to Buster 40ae34f9d77afc42face58eff3338b7b1d1ba469. Build one supplied live.c with the repository's Clang on its supported x86 host, with -O1 -g1 -march=native -fwrapv -funsigned-char -std=gnu17 and the Buster src and src/buster/compiler include paths. Run it with the normal preprocessor options and one C input. The independent whole-unit parser runs after each full source capture. These measurements establish exact row production and its timing relative to end of input. Full native throughput requires a separate process comparison.
