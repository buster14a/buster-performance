# Native prefix objects and reconstructed reference records from original C input

The native driver stopped at four declaration boundaries per source while the same original preprocessor still had active source contexts. Each run produced an ELF from the available original tokens. Separate runs continued to EOF and reproduced the ordinary objects. At SQLite window 36 (606,167 tokens), all 1,251 common named functions already had their final body bytes. Translating early relocation targets to final symbol and section identities made 1,238 complete functions reusable. The reconstruction replaced 312,315 machine-code bytes and all 4,631 RELA records for those functions. For Buster at window 76 it replaced 270,572 bytes and 336 RELAs across 104 functions. Both reconstructed ELF files matched their entire independent reference byte for byte. [SQLite function census](sqlite-symbolic.tsv), [Buster function census](main-symbolic.tsv), [all four checkpoints per unit](reconstruction.tsv).

The reconstruction uses the final symbol table, destination section layout and reserved relocation intervals. It clears selected intervals, fills them from the earlier bytes and fixups, then compares the whole file. Mutating a text byte or a relocation addend changed the resulting digest. The SQLite window-36 reconstruction was linked with the SQLite shell and ran four scripts against a Clang build with matching stdout, stderr and exit status. The first Buster checkpoint had no common emitted function. [Source](source.patch), [revision](revision.tsv), [drivers, individual fixups, comparisons and SQL runs](runs.tar.gz).
