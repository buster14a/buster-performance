# Check consecutive complete declarations together

The source producer groups C declarations up to a 1,024-token limit. An individual declaration that exceeds the limit runs alone. For each group it constructs the active expression graph once, runs the usual checker and retires its allocations. It skips groups made entirely of exact no-action or DROP records. On SQLite it checked 7,298 declarations in 676 groups. On Buster it checked 12,518 declarations in 1,477 groups. Every ordinary per-declaration graph and checked-result fingerprint matched. [SQLite and Buster oracle](oracle/)

On one Ryzen 9 7940HS core, five ABBA/BAAB rounds compared this producer with the ordinary dense expression reader and checker. Both processes stopped after processing the same source and checker stages. On SQLite the paired elapsed difference was −16.375 ms in five of five rounds, with −16.629 ms system CPU time, −0.200 ms user CPU time and −41,088 KiB peak memory. Buster was −80.472 ms in five of five, with −31.391 ms user CPU and −161,086 KiB peak memory. These processes stop before diagnostics, lowering and output. They used a different machine from the 9700X target. [Dense-control samples](dense-samples.tsv) and [paired results](dense-paired.tsv)

A separate campaign compares individual-root checking with the batched producer in the same native build. At 1,024 tokens, SQLite saved 19.333 ms in five of five rounds and Buster saved 46.568 ms in four of five. Each limit has its own control observations. Machine load differed between the separately scheduled campaigns. [All observations](samples.tsv) and [256-, 1,024- and 4,096-token results](paired.tsv)

Apply source.patch to the base recorded in provenance.tsv. The portable benchmark accepts the compiler, output directory, workload name, dense or one control, token limit and ordinary compile arguments. The verifier mode uses BUSTER_SOURCE_ROOT_BATCH=1024, BUSTER_CHECK_BODY_SOURCE_ONLY=1, BUSTER_CHECK_BODY_ADMIT_ALL=1 and BUSTER_CHECK_SOURCE_DECLARATIONS=1. The ordinary comparison uses BUSTER_CHECK_BODY_WHOLE_FINGERPRINT=1 and BUSTER_CHECK_SOURCE_DECLARATIONS=1.
