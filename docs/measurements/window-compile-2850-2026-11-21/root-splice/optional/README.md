# Source-keyed native lowering and source provenance

This private experiment publishes source-token-keyed T/C/X tapes before the ordinary reader emits the current chunk. At an ordinary expression pop the lowerer attempts to replay a retained tape, resolves local slots and global symbols, sets the address-taken bit on local addresses, and emits the original source tokens. The optional path retains the ordinary graph. The native consumer handles straight-line integer returns and simple assignments with a three-entry store/discard sequence. The remaining graph follows the ordinary lowerer. No end-to-end throughput claim is made here.

* Source base `84a7d3d76891d6c393497e62e6aff38f2b162fc2`, independent producer dependency `2af4484e2`, and exact consumer `30b12298b07ed93dd84a450428a00e5d6916aec9`. Apply `producer.patch` and `consumer.patch` in order to the base. Native Develop executable SHA-256 was `fbc1bd4b27afe978d39ba6d96698a3d3d6589cb3b63a0e7986a13be369a06df8`.
* `artifacts.tsv` and compressed per-file tables retain every ordinary versus experimental exit status, diagnostic match and ELF digest from 1,372 corpus TUs plus the fixture under default, -g, -Wall -Wextra and -Weverything. SQLite took 4,866 roots/9,431 rows under default; Lua 817/1,327; musl 2,492/5,050; compiler main 762/1,512. All four corpora refused all under -Weverything. One original debug producer crash in musl is preserved below.
* The standalone shadow measurement performs a separate ordinary lower with native source tracking, compares it to the real source-keyed consumer's lower, and runs an owner-instrumented ordinary lowering to link the true token back to its front-backed record. `native-and-provenance.tsv` records all row/class/value and source-token comparisons. The logs in `*-provenance.txt.gz` contain one `splice-result` header per TU, in frozen input order, then 16 integer columns per selected row: root graph node, root opcode, root token, root rows, row position, origin opcode, native kind, origin token, left/right tokens, previous origin, parser parent, actual ordinary token, ordinary owner-inventory token, native class, nearest explicit enclosing cast-close or root.
* The callee's left token explained all direct call sources across the four corpora. The nearest explicit enclosing cast-close or the root explained all discard sources. General conversions and the remaining postponed emit cases require further source modelling; only the verified subset is consumed here. The manifest names still use `consumer` from the qualification runner and identify the actual default taken sets.
* `matrix.py` generates 864 distinct functions across nine integer types. All 36 grouped policy/TU cells have the same exit status, diagnostics and ELF. The separately recorded mutation tables show changed debug ELF for wrong source owners and constant payloads. Omitting the local ADDRESS_TAKEN bit made SQLite's sqlite3FkCheck invalid in Tier 0. Removing the local-class veto survived these samples; no affected row was observed.
* Reproduction: build the patched tree with `./build.sh --config Develop`. Set `BUSTER_CORPUS_ROOT` to the frozen inputs arranged as in `corpora.sh`, and `BUSTER_COMPILER_SOURCE` to the frozen compiler source for the fourth corpus. Run `SPLICE_POLICY=debug python3 elf.py /path/to/compiler reproduction fixture sqlite lua musl main`, or replace debug with default, wall, or all. `python3 matrix.py /path/to/compiler` runs the generated group. The native shadow uses `measure-node-machine --shadow --window-rows --front-first --passes 0` with the same inputs, `NODE_PROOF_NO_FP=1 NODE_PROOF_POINTERS=1 NODE_PROOF_CALLS=1 NODE_SOURCE_ROWS=1 NODE_PROOF_NATIVE=1 NODE_SPLICE_LOCATIONS=1 NODE_SPLICE_CHECK=1 NODE_SPLICE_DUMP=1 NODE_SPLICE_REPORT=1`.
