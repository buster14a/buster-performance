# Compiling source windows through the ordinary driver

The ordinary command `compiler --node-window-source --lanes 1 -c` runs a bounded independent source T/C/X producer before graph construction. The ordinary checker handles every interval the producer declines. A committed interval is physically replaced with a checked value. Its source-derived native tape is mandatory at the actual Tier 0 lowering request. Local reads, writes and surviving static references are replayed by their respective warning and selection consumers. The default invocation continues to use its ordinary input graph.

See sweep.tsv for absolute instruction counts, paired deltas, faults, full graph composition and native counts. For each source snapshot, the seven interleaved PMU rounds compare the parent plain binary, the same executable plain, the expensive original proof, the new source producer with dry fallback and the new ordinary production option. The five arms share their complete SQLite object. Timing is local 7940HS; process and kernel costs appear separately in the raw table. Ranges include all seven round differences, with no sample removal.

Source 156981782 introduces the ordinary flag and removes graph-proportional shadow columns. 390db993b gathers only complete eligible parser subtrees and removes the duplicate comparison front. 7af743487 caches diagnostic controls and collapses repeated mandatory dispatch. c2051fad0 retains native receipts only at actual graph leaves and scans newly appended types for special address spaces. 57e3b4519 adds bounded builtin type preparation, unsupported-policy fallback, allocation fallback, vectorized declaration discovery and the previously merged weak-alias debug fix. 8714ec361 screens mandatory lookups with a bit per source token. 8a8ade72e constructs declaration lines directly at their source chunk’s slots. 196201cb4 replaces three per-token object/symbol columns with a single bit per static object. d84cdf398 scans parser action classes and literal/name counts with AVX-512 and avoids a per-chunk graph batch flush. bb86d4685 omits the remaining graph-numbered verifier and its native output arrays. Only revisions with a completed seven-round run and an exact semantic graph are included in the table and patch chain.

Each source directory includes a patch on its predecessor in table order, beginning at 7ef9900685609381d183a482a01cdb9bf481bff6 from the source-root-full archive. All identity comparisons use ordinary source compilation. The old graph-numbered shadow is used only to count intersecting native opportunities. Dry fallback retains the source proof and rejects publication at the last pregraph gate. It does not erase already-created graph nodes. The benchmark compiler uses the same object backend in every arm.

The current producer covers integer return operands and discarded plain scalar assignments with exact native shapes. Frozen SQLite admitted 4,215 source intervals including 2,263 whole returns, removed 6,218 graph nodes and emitted 4,213 mandatory splices. The other two retained sites were in unreachable branches. Raw surviving semantic checks include 317,405 nodes and 258,577 ordinary fallback edges. Every full ELF and source-tagged machine row in the default native oracle matches. The complete four-corpus default, debug, Wall/Wextra and Weverything collections are recorded where qualified. During the tracked-source debug sweep on the historical baseline, weak-alias/mixed-unused.c reproduced the separate debug string table ordering issue fixed on main by PR 3225.

The frozen bb86d4685 source-only executable retired 1,416,686,870 user instructions at the local seven-round median. Its same-image ordinary, dry and old proof modes took 1,380,304,174, 1,428,268,838 and 2,149,821,371, respectively. The paired difference was +36,382,691 instructions, with +708 median process minor faults and +5.13 ms wall (−30.43 to +16.22 ms), versus same-image ordinary compilation. Source production recovered 11.57 million instructions relative to dry publication. These results establish cheaper source production without a speedup over ordinary compilation. Hardware and compiler are the local screening setup, so treat its noisier wall observations separately from the locked Ryzen 9700X Release evidence.

At the final head, the four-corpus plus three-fixture comparison exercised 1,375 translation units and 991,983 sourced native entries under each of four policies, or 11,000 real compiler invocations in total. Every status, standard output, diagnostic, complete ELF, native entry, local-slot attribute, call and argument class agreed between the actual ordinary and production drivers. The default and debug policies each compacted 8,219 source roots, removed 11,977 ordinary graph rows and used 7,029 mandatory native splices; -Wall -Wextra gave 4,458, 4,701 and 3,510. -Weverything took the ordinary path throughout. An additional 8,617 tracked file/policy pairs had identical same-image on/off outputs, including 2,319 admissions. The historical uncorrected parent differed at exactly one tracked debug object; alias-witness.txt records the ordinary A/A problem and the fixed-head controls. The focused directory contains another 112 adversarial source/policy pairs with 261 admissions and 216 emitted splices, all outputs equal.
