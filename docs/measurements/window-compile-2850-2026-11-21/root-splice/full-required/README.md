# Source-selected whole-root and operand compaction in real object emission

The joint research build at `3cfa72aaf0cebe8a7e0403359c74e3c65244f931` supports scalar source-proven returns, scalar local reads/stores with access receipts, and the distinct straight-line operand replacements. Its Develop compiler SHA-256 is `c4fe9a759ad38a132f72b6c6f47753f3b8d35f8186ce3c54e5d446195a421729`. The patch is relative to the earlier operand experiment at `2b8932e6d`.

Every table compares the ordinary driver to physical source compaction with mandatory native replay only. Both modes compiled all 1,372 corpus translation units and three fixtures. The four policies were default, debug, Wall/Wextra and Weverything. All 11,000 compiler invocations matched on exit status, diagnostics, ELF SHA-256 and every byte of the observed backend input. Each full pass covered 991,983 native entries across 8,028 bodies, 55,179 local class/flag pairs, 37,035 call descriptors and 89,605 argument classes. The debug pass includes every row's source token. The witness observes each actual Tier 0 input before the object's streamed part storage is recycled, and writes in stable body order after collecting all parts. The compared call descriptor fields are the target, argument start/count and variadic byte. The emitted object comparison includes final debug and symbol relocations.

The default and debug policies each admitted 8,335 source roots, removed 12,218 graph rows and executed 7,058 mandatory native replacements. Wall/Wextra admitted 4,466, removed 4,726, and executed 3,513. Weverything kept the ordinary graph throughout. The data include no mandatory replacement with an unadmitted key. Source-root admissions include code that does not reach native lowering. The per-file tables report both counts.

The four real corpus admission/removal/execution counts under debug were SQLite 4,215/6,218/4,213, Lua 655/869/655, musl 2,847/3,865/1,891, and compiler main 605/1,244/286. These are actual source-graph replacements. They do not establish a throughput gain.

To reproduce, arrange the frozen corpora as shown in `corpora.sh`. Export `BUSTER_CORPUS_ROOT` for SQLite, Lua and musl and `BUSTER_COMPILER_SOURCE` for the frozen compiler source. Run `python3 compact-native.py /path/to/compiler result.tsv --policy debug --modes ordinary,full fixture statics runtime sqlite lua musl main` for each of `debug`, `default`, `wall` and `all`. Each result row includes SHA-256 digests of ordinary diagnostics, emitted object and native stream, plus the independent admission/replay counters.
