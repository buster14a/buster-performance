# Emitting source-derived direct calls in the ordinary native backend

This research build at `a29d179cb4434fb3de0d8109bf8e8f5024d34555` independently constructs and consumes the scalar ABI descriptor for a direct, prototyped call with a bounded set of simple integer/pointer arguments. The explicit return or discard wrapper and the direct callee token identify ordinary source locations. Local slot and global symbol relocation happen when the backend pops the expression. The ordinary graph still provides checker diagnostics, reachability and object selection in these experiments.

The three modes are ordinary, canonical source registry plus native call consumption, and the same path with a temporary type view deriving additional function-designator decay types from the original declarations. The final mode records a stable pointee recipe and checks the ordinary callee conversion later. It refuses to publish a usable ABI call descriptor with an argument type that would escape the temporary view. The native ABI consumer admits only fixed System V prototypes with matching primitive result/argument types and symbol/slot relocations. Canonical registration and temporary type derivation are separate measurements in each table.

All 16,512 real compiler invocations across four corpora, four focused files and four policies matched on exit status, diagnostics, full ELF and the entire streamed native witness. The witness includes per-entry source tokens under -g, local classes and flags, callee symbols, argument ranges and variadic flags, and every argument class. The default and debug passes each compare 991,986 emitted rows across 8,027 functions. The wider view consumed 6,256 direct calls across those files, including 3,367 in frozen SQLite compared to 862 using only the source registry. It checked all 17,914 canonical callee conversions selected by native X, including 14,411 derived with the temporary types. No row escaped with a provisional ABI type and there were zero missing or incorrect canonical receipts. Wall/Wextra replayed 6,245 direct calls, and Weverything conservatively retained the ordinary path throughout. One negative fixture is rejected by ordinary compilation and the matching status and diagnostics are intentional.

A separate 439-function generated matrix and 224 attribute/shape/policy combinations matched ordinary outputs throughout. On the independently linked execution fixture, the positive source image returned the also-observed Clang result. Changing the callee's source token changed the debug ELF and native witness, changing a constant argument changed both and the executable's return code, and changing its symbol broke emission. Invalid source signatures/conversion-class/variadic receipts were refused. The qualification on `getcwd.c` exposed an incorrect LOCAL_ADDRESS for a VLA's pointer slot in the older registry experiment. The final code uses the ordinary address lowering routine, which loads the pointer for dynamic storage. `vla-controls.tsv` includes the original object mismatch and corrected runtime equivalence across fixed, dynamic and pointer storage.

Set `BUSTER_CORPUS_ROOT` and `BUSTER_COMPILER_SOURCE` as described in `corpora.sh`, then run `python3 compact-native.py /path/to/compiler run.tsv --modes ordinary,calls,viewcalls --policy debug fixture callfixture callrefuse vla sqlite lua musl main` for each policy. `CALL_VIEW_TESTS=1` enables the temporary view in the standalone generated, attribute and execution scripts. The source patch is relative to `2b8932e6d`. These results establish the observed ABI and native semantics. They do not establish a net compile-time gain.
