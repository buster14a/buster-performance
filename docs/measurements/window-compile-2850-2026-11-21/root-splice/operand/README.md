# Removing source-proven operand interiors in the ordinary compiler

The reader substitutes a typed semantic leaf for a closed, multi-node operand under its original conversion/cast wrapper. The independent source key reciprocally identifies the leaf and its surviving wrapper. A committed root must replay its native tape whenever lowered. Compiling without optional source lowering exercises this path directly. A compact static-object tree supplies references lost when the reader skipped the original nodes. This first joint experiment physically removes operands under a quiet, scalar, automatic-access-free gate; its successor covers singleton return roots separately.

The exact research head was `2b8932e6d`, Develop executable SHA-256 `68377351446c0d0e69c58602785806283a8e0d32f8375b0d508c832fdc0caf21`. `operand.patch` is relative to the optional source/native prototype `30b12298b07ed93dd84a450428a00e5d6916aec9` documented in the adjacent optional folder.

Every matrix row is a real one-lane ordinary driver compile. The matrix covers SQLite, 34 Lua source files, 1,336 musl source files, the compiler main unit and three fixtures under default, debug, Wall/Wextra and Weverything. At each policy the runner compiles all 1,375 units in three modes: ordinary, required compact replay only, and compact replay with optional source-native lowering elsewhere. All 16,500 invocations match by exit status, diagnostics, object bytes and lowerer stream. The witness takes all body-local kind, class and 64-bit payload words; source tokens on -g; every local class/flag; every call's target, first argument, argument count and variadic byte; and all ABI argument classes. ELF equality covers later runtime/table relocations. Lowering sources and object references are independent observables. This operand build is qualified with one lane; its early witness cannot serialize simultaneous appenders in body order.

Under default and -g the required path consumed all 62 admitted roots and removed 115 interior graph rows. Each of those passes covers 991,983 native entries, 55,179 local slots, 37,035 call descriptors and 89,605 argument classes across 8,028 functions. SQLite contributed nine separate operand removals, all nine consumed; the optional path independently replaced 4,763 SQLite expression pops in the same compile. Wall/Wextra and Weverything admit no compulsory roots in this initial family. The emitted graph is a partial proof of integration, not throughput acceptance.

On `unique-static.c`, the erased subexpression was the only use of both private definitions. Ordinary and required modes emit both symbols byte identically, link to the external harness and run successfully. With the isolated controls in `reference-controls.patch` applied, dropping the static receipts or skipping the mandatory native consumer fails emission; forcing ordinary traversal of the erased subtree also fails. `static-reference-controls.tsv` records the result for the separate mutation image. Its SHA-256 is listed in `control-image.txt`; the fixture-only observations do not depend on the native stream witness.

For reproduction, set `BUSTER_CORPUS_ROOT` to the frozen tree laid out in `corpora.sh`, and `BUSTER_COMPILER_SOURCE` to the frozen compiler sources. Run `python3 compact-native.py /path/to/compiler comparison.tsv --policy debug fixture statics runtime sqlite lua musl main` for each policy (default/debug/wall/all). The runner sets only the mode under test in the compiler environment. `REFS_ARTIFACT_ONLY=1 python3 refs-mutations.py /path/to/mutation-compiler` covers static symbol liveness and execution.
