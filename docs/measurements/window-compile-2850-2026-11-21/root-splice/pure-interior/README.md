# Closed integer arithmetic below ordinary graph parents

This experiment replaces a complete arithmetic operand with its source-derived checked integer value during parser postorder and before assigning ordinary graph node IDs. Its parent remains an ordinary graph expression. The parent sees the operand's original operator token, unqualified `int`, rvalue category, ICE flag, 32-bit integer payload and zero fault state. The ordinary backend compiles the result through its normal entry, as the full native stream verifies. The frontend leaves unsupported and faulting expressions to the ordinary checker.

The source patches build on the frozen ordinary source-window experiment at `bb86d4685`. Apply the five incremental patches in table order after the [lean source reader patch stack](https://github.com/buster14a/buster-performance/tree/c8fdac6121f5fdd68ce42e78e27eaa10286e9e6c/docs/measurements/window-compile-2850-2026-11-21/root-splice/source-root-lean). Private controls permit causal measurements within each compiler image.

| Revision | Source change |
|---|---|
| `2549fd7dd` | Gather contiguous integer-literal arithmetic subtrees with exact source parentage, apply the source arithmetic table, and publish the resulting operand. |
| `9286397fd` | Retain original syntax for ordinary shift, multiplicative and conditional diagnostic consumers. |
| `15d3ac6c8` | Examine only arithmetic intervals with possible literal subtrees. Compute candidate masks over groups of 16 parser actions. |
| `f5e195416` | Decode bounded number spellings with the compiler's regular integer decoder. This includes hexadecimal and octal constants of type `int`. |
| `3bf580002` | Produce arithmetic candidate masks in the existing pass that gathers the chunk's numeric literals. |

The ordinary full semantic graph on frozen SQLite contains 323,623 nodes. A diagnostic census found 2,617 maximal quiet integer arithmetic trees with 5,800 removable descendants across 30 kinds of ordinary parent. This ceiling includes typed constant values that the bounded integer-literal grammar cannot recognize. The compressed `graph-ceiling` tables retain each row's original root and operation.

The plain decimal source proof at `2549fd7dd` admitted 1,867 actual SQLite roots and removed 2,546 nodes. It passed all four frozen corpora for each of four warning and debugging configurations, including the complete sourced native stream. An independent arithmetic generator then found 77 option-specific differences across 4,158 expression, parent and policy pairs. The ordinary diagnostic code inspects the original shift operator and its signed literal operands, and the original operand shape of certain invalid divisions. Seven reduced source forms and ordinary/changed diagnostics are included under `rejected-diagnostics`.

Guarding those shape-sensitive parents reduced decimal-only SQLite admission to 1,599 roots and 1,771 deleted nodes. All 321,852 surviving graph values and 263,024 fallback edges matched. The guard removed all 77 adversarial differences. At the masked revision, 8,617 tracked source/policy pairs and 11,000 canonical real compiler invocations matched status, diagnostics and complete ELF. The four-corpus native check includes each sourced entry, its slot flags and its call/argument descriptors. Across all frozen translation units each of the four policies admitted 8,678 roots and removed 12,965 rows.

Using the ordinary integer spelling decoder added 757 roots and 2,988 removed SQLite rows. The source producer now compacts 2,356 roots, preserving 318,864 semantic rows and 260,036 fallback edges. Only 40 removed rows also belonged to the previously measured complete return/store window family. The remaining 4,719 are independent opportunities. This overlap is measured against the ordinary graph and does not establish a combined executable. The 26,370 pre-existing independently warning-qualified whole windows account for 137,236 ordinary rows, and each verified against its complete source root and record count. The new producer removes 3,744 rows outside their union. Of the 2,356 physically compacted SQLite children, 1,842 have a final sourced native CONST entry whose operator token and low 32 value bits match the checked result. There are 1,875 final native rows at these tags. The remaining 514 lack a native entry tagged with their own token.

The `mutations` directory contains controls with one corrupted receipt at a time. Removing ICE turns a valid computed null-pointer initialization into an error. Clearing the stored integer changes a required static assertion. Moving the graph source token to the first literal changes the native source-token tape on mutation.c even when ELF bytes agree. On the separate warning.c fixture it also moves constant-conversion warning locations and loses a warning. The unmodified receipt agrees with ordinary compilation on every output for this fixture.

Each seven-round local measurement interleaves real single-lane SQLite object compiles and retains complete ELF hashes. Dry discovery leaves all ordinary graph nodes in place. Production publishes the qualified child and its ordinary parent consumes it. `performance.tsv` reports median paired differences with all round minima and maxima on the local Ryzen 7940HS. The raw instruction, user/kernel cycle, fault and elapsed-time samples are in each revision's `perf/pairs.tsv`. `qualification.tsv` distinguishes frozen corpora, tracked source tests, generated adversarial tests and the Clang comparison. Results from an exploratory unguarded source snapshot are retained to make the earlier failures reproducible.

The private execution control is `NODE_PURE_INTERIOR=1` with the normal `compiler --lanes 1 -c` driver. Set `NODE_PURE_INTERIOR_MASK=1` for screened intervals, `NODE_PURE_INTERIOR_SPELLINGS=1` for general integer spellings, and `NODE_PURE_INTERIOR_FUSE=1` to obtain those masks from the literal collector. The unmodified driver with no such controls is the baseline. `NODE_PURE_INTERIOR_DRY=1` leaves the graph unchanged after source discovery. `NODE_PURE_INTERIOR_REPORT=1` emits accepted source root tokens and ordinary node removals.

On local frozen SQLite, the masked decimal-only producer at `15d3ac6c8` cost 1,378,933 additional retired user instructions versus its ordinary driver. Reusing the canonical integer spelling decoder at `f5e195416` produced a net reduction of 2,793,844 instructions in all seven rounds (−2,798,687 to −2,793,664) and 276 fewer process minor faults at the paired median. The expanded dry producer cost 4,179,683 instructions, and publication recovered 6,973,481. Wall time was inconclusive. At `3bf580002`, collecting the masks when the normal reader extracts its numbers saved a further 312,655 instructions against that same binary's independent mask collection. Its full fused/ordinary delta was −1,560,177. These are within-image comparisons at each revision. The workstation and the 9700X have different page-fault behavior, and the wall-time distributions are reported independently.

The expanded integer rule at `f5e195416` passed all 11,000 canonical ordinary/option invocations. Every status, diagnostic, object and sourced native stream agreed for all 1,375 units under each of the four policies. SQLite admitted 2,356 child roots and removed 4,759 nodes, Lua 781 and 1,986, musl 2,895 and 4,005, and Buster self 27,225 and 67,264. An additional 4,158 generated parent/policy pairs and 1,251 randomized or lexical pairs matched. Across 1,524 Clang comparisons, ordinary and source-window Buster always agreed. Buster and Clang matched exactly on status and normalized ordered diagnostics in 1,060 cases.

On the frozen Buster compiler source, the expanded rule reduced retired user instructions by 94,815,651 at the median of seven actual object-compile pairs (94,800,433 to 94,840,346 fewer). The local dry producer cost 36,580,715 user instructions and publication recovered 131,400,809 compared with dry discovery. The paired median process fault change was −4,118. The elapsed time difference ranged from −66.979 to +13.527 ms. Exact source, object hashes and raw counters are in the self measurements.
