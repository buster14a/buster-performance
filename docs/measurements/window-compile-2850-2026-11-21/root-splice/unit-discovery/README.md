# Four-corpus source screening for the checked windows

These diagnostic changes use the explicit integer arithmetic or return window. No discovery gate became a default. Measurements use one real ordinary multi-input object compiler process per corpus on the local 7940HS in Develop configuration. Each complete workload was warmed and then measured in three randomized mode orders. Every observation checks the complete output object manifest and stderr. The laptop wall observations include the perf process and shared machine effects. The independent 9700X ordinary-compile and true wall measurements for the unmodified arithmetic feature are pinned separately. [Integrated production feature](https://github.com/buster14a/buster-performance/tree/87ff749714d4d6770e48df43969301f63c8c9efb/docs/measurements/window-compile-2850-2026-11-21/83dfc8e8c)

| Integer arithmetic gate | Full musl instructions in millions, enabled minus ordinary | Musl graph roots retained |
|---|---:|---:|
| Same-image complete arithmetic window | +11.00 | 2,895 |
| Classify adjacent number and operator shapes, minimum one | +11.08 | 2,895 |
| Require a typed, quiet integer operation, minimum one | +5.94 | 2,640 |
| Require four typed, quiet operations | +3.74 | 1,635 |

The integer gate reads the reader's existing source-order class bytes. Its broad version counts literal/operator patterns including floating-point source. Of 301 musl units with at least 32 such patterns, 198 accept zero arithmetic roots. The typed version also verifies parsed integer types, source parentage, diagnostic-sensitive contexts and the shared fold. It eliminates all false-positive units in these corpora. The adjacent typed pattern misses 255 legitimate grouped roots in musl's `__ctype_b_loc.c` and one Lua root in `linit.c`. These units take the complete ordinary graph. Each of the 1,372 units was compiled at each measured typed threshold 0, 1, 4 and 16. All 5,488 admission counts agree with the selected-unit prediction, and every complete object matches the original oracle. The separate full-workload runs compare stderr for each mode.

The regular return and explicit-void gate uses the ordinary checked return type and parser classes to mark possible end tokens. The normal independent checker still establishes the accepted expression and its native tape. Requiring one candidate bypasses 902 of the 1,336 musl units and preserves every ordinary admission in all four corpora. Reading the configuration once per compiler invocation isolates the cost of the scan and optional marks. On musl the ungated, unit-only and marked modes retire 5.54, 2.71 and 3.21 million fewer instructions than ordinary, respectively. Marked endpoint scanning costs 2.27 million additional instructions against the ungated production window in all three paired rounds. Across 528 additional literal, grouping, chunk alignment, warning, debug and Tier 1 cases the initial marker implementation preserves every admission count, diagnostic stream and object. Both physical window features remain independently opt-in.

Each directory contains its exact source patch and local-source revision, corpus admissions, full manifests and PMU samples. `comparison.tsv` reports median, minimum and maximum mode-minus-base differences, with instructions and cycles in millions and wall in milliseconds. `plain` means ordinary compilation of the diagnostic binary. `atN` is the broad integer seed threshold, `tN` the typed threshold, `uN` the regular unit-only threshold and `mN` the regular marked-terminal threshold. `full` is the current regular consumer in the diagnostic image and `orig-full` the original production regular option. The separately compiled arithmetic base is `a60859270`. These particular diagnostic changes predate the integrated parser source-map patch; their production-equivalent parser uses a populated source index column. Their option source deltas do not introduce another direct read of that column. `FROZEN/` denotes the canonical source collection and `COMPILER_SOURCE/` the pinned Buster source checkout used by the existing series.
