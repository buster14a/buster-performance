# Source-proved direct calls using deferred function-decay recipes

The compiler at `3749bdacc` retained an independently constructed function-pointee recipe when the canonical decay pointer was absent. The source producer uses this recipe for the native call target and fixed argument ABI types. Once normal graph checking has run, the witness verifies the canonical type associated with the same source token. Existing source types and the normal graph remain available to the rest of the compiler.

On SQLite the ordinary native emitter consumed 2,909 direct calls from these recipes and resolved all 9,379 source-callee records it checked. The default four-corpus and fixture run consumed 4,967 physical native CALL rows across 1,376 translation units. The compiler produced identical serialized backend inputs, exit statuses, diagnostics and ELF files across 11,008 invocations under the four policies. The generated run adds 439 functions over 32 compiled pairs, and the attribute matrix adds 224 pairs. The runtime controls cover corrupted source tokens, targets and arguments.

Set `BUSTER_CORPUS_ROOT` and `BUSTER_COMPILER_SOURCE` as described in `corpora.sh`.
