# Declaring source-backed object bases

At the real checker, physical spellings selected all 17,486 SQLite base declarations. The full ordinary and source-backed objects matched on both SQLite and Buster. On the 9700X SQLite took 113.793 ms ordinary, 139.930 ms with source-backed fields and 142.792 ms with fields and base lookup.
