# Native object compilation with body-local warnings

This experiment extends the ordinary single-core native emitter at `387855378`. When the source emitter accepts a function, the checker runs its warning consumers before retiring its local graph. It retains original macro locations, notes and resolved diagnostic groups in the preprocessor arena. The final unit reading publishes those groups. A recovery reading can discard the speculative groups and render its own. Folded branch intervals and the local return-flow classification give warnings the same control-flow facts used in the ordinary compiler. The variable-use checker bounds its seven per-token arrays to the current function. [Source changes](implementation.patch), [source revisions](commits.tsv) and [native emitter](../387855378/README.md)

The independent clean compiler at `fbef2d68d` and the native candidate at `f0d41668b` matched in all 385 fixture and policy combinations. Every comparison included process status, stdout, stderr and every ELF byte, including absence of an output file on error. The suite exercises macros, diagnostic pragmas, folded arithmetic, evaluation order, enum conversions, variable use, constant shifts, printf formats and hard semantic errors on both sides of a source-owned function. Separate runs record the number of source-owned functions and remaining unit graph nodes. The checker unit was compiled without optimization for quick iteration. A local trial of a variable-length array previously stored its temporary graph indices in `CheckInputVla.bound_node` and the cached runtime size. A later ordinary reader reused the retired slot. Both a 49-byte standalone function and musl’s `dcngettext.c` reproduced this with zero source-owned native functions. Their ordinary reader now retains the VLA throughout. The four controls produce the same 800-byte and 7,800-byte objects, respectively. The independent clean Develop compiler and each frozen native candidate matched all 6,860 real source/policy comparisons across one SQLite unit, one Buster unit, 34 Lua units and 1,336 musl units, each under five policies. Every case compared exit status, byte-for-byte stdout and stderr, and the SHA-256 of the complete emitted object or its absence. Each revision included 863 expected compilation failures under strict warnings, and all succeeding SQLite and Buster compilations retained the original complete ELF objects.
