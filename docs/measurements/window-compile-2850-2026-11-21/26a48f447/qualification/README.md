# Local object and runtime comparisons

A Develop build of the candidate and an equivalent public-main source build compiled all four corpora with default warnings, `-Wall -Wextra`, and `-Weverything -Wno-c++-compat`. All 4,116 individual comparisons matched the complete native object or absence of one, exit status, standard output, and standard error. The corpus TSVs record the returned values and SHA-256 digests. The directed suite checks the same properties for three language standards, four policies, and one or four lanes. The padded source cases include Clang runtime comparisons.

The relocation fixture contains local and external calls, a function pointer, a switch table, global and thread-local references, inline assembly and an interior data pointer. Five window sizes, one and two lanes, and ten compilation policies produced 100 exact comparisons. All 70 accepted configurations linked against the supplied provider and printed the same output as Clang. Both compilers diagnosed the remaining 30 combinations for unsupported options. A second fixture exercises a naked function with both symbolic displacement and immediate fields in one instruction plus another function containing an assembly-local label. All 100 baseline/candidate configurations matched byte for byte, linked and printed the same output as Clang. The separate poison run compares 20 combinations of window sizes, debug and verifier settings. The native linker, x86 encoder and all eight seeded checker shards have their output retained here.

The GDB probe observes the optimized Develop binary at completion of each ordinary window's code half. The aggregate records in `count-sqlite.log` and `count-main.log` count the resolved fields and encoder columns whose lifetimes end with each body. Durations for the native Release comparisons were collected separately on the Ryzen 7 9700X.
