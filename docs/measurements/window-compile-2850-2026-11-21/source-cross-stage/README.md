# Source evidence across physical names, bindings and emitted statements

The connected native compiler resolved 24,323 physical member spellings against their declarations on SQLite. Each selected field slot, bit offset and inherited qualifier matched the reference and the full native ELF was byte-identical. The first connected implementation was slower than the ordinary full compilation on CPU 2. Both warnings and matched process measurements are retained in the packet. [Source-to-member runs and full patch](source-to-checked-members.tar.gz).

The binding studies publish ordinary source-use results at lexical scope close and retain independent checks for late completions, error recovery and corrected identifiers. [Full-unit binding publication](source-bindings-all.tar.xz), [body-local binding publication](source-bindings-local.tar.xz).

The source statement experiments remove eligible graph work before typed emission. The store variant removed 9.81 percent of SQLite graph nodes. The call-result variant also tested direct assignment of eligible call returns, full native object equality and independent fresh-process counters. The local filtered variant removed 44.25 million user instructions in 12 of 12 pairs. [Store receipts](source-store-statements.tar.xz), [call results](source-call-assignments.tar.xz).

On a subsequent Buster self-build the field-first branch exposed an unresolved fallback for a body whose parser names had been withheld. The SQLite scope and timing in the packet are unchanged.
