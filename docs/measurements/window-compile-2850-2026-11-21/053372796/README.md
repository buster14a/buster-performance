# Sparse selected operands

A selection stores its runtime or proof-only operand in a 16-token pool block. A unit with no selection keywords needs no directory. Partial diagnostic readers that own a dense private column continue to use it. All 6,860 object, stdout, stderr and exit comparisons matched independent ordinary compilation, including 863 expected nonzero exits. The eight checker shards passed 850,926 assertions. Six fresh process groups per workload and three separate counter samples per arm ran on the local Ryzen 9 7940HS using matched Develop builds. The timing control is the exact parent 40ae34f9d.
