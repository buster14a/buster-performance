# Binary64 x87 constants in Tier 1

[PR #3138](https://github.com/buster14a/buster/pull/3138) at `a695f9d2c5240fd49619809347c80d784e8ffbc4` compared with [#3136](https://github.com/buster14a/buster/pull/3136) at `4842bd968ea3a18c707bb90df0fc3bb85524b59c`.

When an F80 literal is exactly a normal binary64 value, Tier 1 can emit a PC-relative `fldl` at its original x87 consumer. The existing binary32 case retains priority. The classifier uses the original significand and exponent bits, including the explicit integer bit. Signed zero, narrower subnormals, extra precision, exceptional values and noncanonical encodings have dedicated coverage. The existing Zen 5 table contains the measured memory form for `FLD_M64`.

Of the 1,336 frozen musl objects, two changed. Together `fmal` and `hypotl` contain three eligible loads, all of the splitting constant `2^32+1`. Their text sizes stayed the same. Under twelve x87 precision and rounding combinations, both compilers and Clang-built musl agreed on all 196,608 function results, exception flags, errno and control observations. A separate 256-bit MPFR interval oracle found the same inherited differences in the three builds of musl `hypotl`.

On the local Ryzen 9 7940HS, affine and polynomial loops took 12.82–13.16% and 10.59–11.02% fewer cycles across four placements. A dependent recurrence took **3.74–4.16% more cycles**. In musl, ordinary `hypotl` took 1.54–2.23% fewer cycles, and cancellation-group inputs took 2.31–3.70% fewer. Wide-exponent inputs gave mixed results. Direct Ryzen 7 9700X confirmation is pending.

Eight generated-code configurations each passed 346,608 comparisons against the parent over 498 constants. Eight independent ELF inspections checked 3,983 PC-relative references to exactly 498 literals apiece. Forty-eight final links with GNU ld and LLD exercised fixed executables, PIE and locally bound shared objects. All 160 raw-IR cases and the pending-exception tests passed. The final compiler passed all 196,436 checker-driver checks across 110,014 child processes.
